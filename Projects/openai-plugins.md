# openai/plugins

## 项目定位
Codex 官方插件示例与默认 marketplace 仓库，定义 plugin manifest 以及 Skills、MCP、Agents、Commands、Hooks 等扩展面。

## 核心功能 / 实现特点
- JavaScript/JSON manifests 为主；plugins/<name> 下以 .codex-plugin/plugin.json 为入口，可附 skills、MCP、agents、commands、hooks 等。

## 主要优点
- 直接反映 Codex 插件生态的官方结构规范
- 把 Skills、MCP、Agent、Command、Hook 统一进插件分发模型
- 已有 Figma、Notion、iOS/macOS/Web/Expo/Netlify/Remotion/Google Slides 等丰富实例

## 局限 / 注意点
- 更像官方生态目录/规范样例，不是单一业务框架
- 插件质量与外部服务能力差异较大，部分插件需要额外账号/权限
