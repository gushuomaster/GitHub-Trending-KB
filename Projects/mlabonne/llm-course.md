# mlabonne/llm-course

## 一句话说明
用分层路线图、文章和可运行 Colab Notebook 帮助学习者从基础知识进阶到训练、量化、评估和部署大语言模型。

## 它能做什么
- 把课程分为 LLM 基础、LLM Scientist 和 LLM Engineer 三条路径
- 提供微调、量化、模型合并、评估与知识图谱等 Colab Notebook
- 覆盖 Transformer、分词、注意力、训练与部署核心概念
- 通过路线图把理论资源与动手实验连接起来

## 怎么利用
官方 Notebook 场景：选择“Fine-tune Llama 3.1 with Unsloth”并在 Colab 打开。输入 → 基础模型、训练数据和超参数；操作 → 按 Notebook 安装依赖、格式化数据并执行监督微调；输出 → 可评估、保存或发布到模型仓库的微调模型。

## 适合谁
想系统学习 LLM 原理、微调、量化和应用部署，并需要可运行练习路径的学生、研究者与工程师。

## 局限 / 注意点
它是课程与资源导航，不是一个统一生产框架；Colab 配额、GPU 型号和依赖版本会变化。训练数据许可、模型许可、评估有效性及云端费用仍需学习者负责。
