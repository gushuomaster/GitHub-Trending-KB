# rlaope/oh-my-hermes

## 一句话说明
在 Hermes Agent 原生 Skills 之上增加规划、研究、编码交接、证据门槛和项目记忆的统一操作层。

## 它能做什么
- 把自然语言请求归类为能力并选择对应工作流
- 为研究、创建、运维和编码交接设置显式证据边界
- 组织 Hermes 原生 Skills、专用角色和模型池
- 记录实际执行结果与项目长期记忆

## 怎么利用
官方 Quickstart：运行平台安装脚本完成配置，随后向 Hermes 提交一个研究或编码任务；OMH 先明确目标与证据门槛，再调用原生 Skill，并保留实际发生的操作记录。

## 实际例子
**官方材料中的工作流：** 官方 Quickstart：运行平台安装脚本完成配置，随后向 Hermes 提交一个研究或编码任务；OMH 先明确目标与证据门槛，再调用原生 Skill，并保留实际发生的操作记录。

## 适合谁
已使用 Hermes Agent、希望增加证据门槛和长期项目工作流的团队。

## 局限 / 注意点
- 它依赖 Hermes Agent 及其模型/工具配置，并增加额外流程与约定；安装脚本会修改本地 Agent 环境，执行前应先阅读脚本和权限范围。
