# obra/superpowers

## 项目定位
由可组合 Skills 驱动的 Coding Agent 软件开发方法论，从需求澄清、设计、计划到子 Agent 执行与评审。

## 核心功能 / 实现特点
- 以 Shell/Markdown skills 与各 Agent 插件/扩展安装面为主；核心流程是 spec→plan→subagent-driven-development。

## 主要优点
- 把工程方法论编码成可自动触发的 Skills
- 强调 spec、实现计划、TDD、YAGNI/DRY 与子 Agent 开发
- 覆盖 Codex、Claude Code、Cursor、Gemini CLI、Hermes、Pi 等多种 harness

## 局限 / 注意点
- 方法论约束较强，不适合所有快速原型任务
- 效果依赖宿主 Agent 对 skill/hook 的执行一致性
