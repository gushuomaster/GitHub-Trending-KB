# calesthio/OpenMontage

## 一句话说明
把 Coding Agent 变成视频制作工作台，从研究、脚本和素材检索一路生成可编辑时间线并渲染成片。

## 它能做什么
- 用 Skills 和 playbooks 编排研究、写稿、分镜、素材、配音与审核
- 从免费素材库或生成模型取得真实动态片段
- 用 Remotion、FFmpeg 或 Blender 组合字幕、图表、音乐和镜头
- 提供可复用 pipeline 定义、schema 与最终视觉检查

## 怎么利用
官方案例：给 Agent 一个 60 秒动画短片主题，它生成脚本和 6 个运动片段，调用语音与音乐服务，再用 Remotion 合成带逐词字幕的成片；README 给出的该案例成本为 1.33 美元。

## 适合谁
制作程序化视频、短片或内容流水线的创作者与 Agent 工程团队。

## 局限 / 注意点
- 外部视频、语音和生成模型会产生费用与版权/许可问题；自动视觉检查可能看不出数据值或叙事事实错误，最终成片仍需人工审片。
