# calesthio/OpenMontage

> 功能和用法按 2026-10-13 当前官方资料核对，不声称等同于历史上榜日版本。历史统计未保存时保持空值，不使用当前值补写。

## 一句话说明
把 Coding Agent 变成视频制作工作台，从研究、脚本和素材检索一路生成可编辑时间线并渲染成片。

## 它能做什么
- 用 Skills 和 playbooks 编排研究、写稿、分镜、素材、配音与审核
- 从免费素材库或生成模型取得真实动态片段
- 用 Remotion、FFmpeg 或 Blender 组合字幕、图表、音乐和镜头
- 提供可复用 pipeline 定义、schema 与最终视觉检查

## 怎么利用
准备 Python 3.10+、Node.js 18+ 和 FFmpeg，在仓库执行 `make setup`；用 Coding Agent 打开项目，明确时长、素材来源、字幕/配音和输出要求。按所选 pipeline 配置外部 Provider，并逐步审核素材与成片。

## 实际例子
**官方 Quick Start → 场景：** 制作雨中城市的纪录片蒙太奇。**输入：** 75 秒、只用真实素材、不要旁白、配音乐的要求。**操作：** 把 README 的该提示交给已配置的 Agent，检索动态素材并剪辑渲染。**输出：** 真实素材组成的成片及质量检查结果，而非仅把静帧加动画。

## 适合谁
制作程序化视频、短片或内容流水线的创作者与 Agent 工程团队。

## 局限 / 注意点
外部视频、语音和生成模型会产生费用与版权/许可问题；自动视觉检查可能看不出数据值或叙事事实错误，最终成片仍需人工审片。
