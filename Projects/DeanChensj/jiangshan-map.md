# DeanChensj/jiangshan-map

## 一句话说明
江山时序是一套覆盖公元前 403 年至今的中国历史交互地图，把疆域、政权、古今地名、人物路线和诗词地标放进可拖动时间轴。

## 它能做什么
- 沿时间轴查看 18 个历史时期和多阶段疆域、行政区、河道及工程变化。
- 点击古城或关隘追踪 2400 年地名沿革、事件和现代位置，并查看历史人物的时空行程。
- 支持可分享深链、CLI 截图与 JSON 查询、浏览器 API、WebMCP 以及 GeoJSON 导出。

## 怎么利用
官方场景：打开带 `year=1415` 的深链查看明永乐十三年地图和应天府；也可用 CLI 输入年份与地点，输出用于 Agent 回答的截图和 JSON 地理历史信息。

## 关键命令
```bash
git clone https://github.com/DeanChensj/jiangshan-map.git
cd jiangshan-map
python3 -m http.server 8000
```

## 适合谁
历史教师、研究者、数字人文开发者及希望交互探索中国历史地理的读者。

## 局限 / 注意点
历史疆域、行政区和地名数据是研究型可视化，不应作为现代主权或精密 GIS 边界依据；语音依赖浏览器合成，CLI/API 与完整资源还需按 README 安装本地依赖。
