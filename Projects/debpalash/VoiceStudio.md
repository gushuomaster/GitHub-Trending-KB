# debpalash/VoiceStudio

## 一句话说明
在本机完成声音克隆、声音设计、视频配音、听写、转录与有声书制作，并通过本地 API/MCP 接入自动化工作流。

## 它能做什么
- 用参考录音克隆声音，或用描述设计新声音。
- 按时间轴为视频生成配音。
- 支持批量语音、有声书、听写和转录。
- 提供 Electron 桌面端、本地 API、MCP 与可选远程 worker。

## 怎么利用
在桌面端安装所需语音模型，输入干净参考音频、文本或视频；VoiceStudio 在本机生成语音或配音文件，Agent 还可通过本地 API/MCP 批量调度任务。

## 实际例子
**场景 →** 给一段产品演示视频制作日语配音。 **输入 →** 原视频、经授权的参考声音和日语脚本。 **操作 →** 在 Dubbing 工作区导入视频、选择/克隆声音并生成定时语音。 **输出 →** 与视频时间轴对齐的本地配音成品。

```bash
git clone https://github.com/debpalash/VoiceStudio.git
cd VoiceStudio && bun install && bun run setup:api && bun run dev
```

## 适合谁
视频创作者、有声书制作者、需要私有化语音工作流的团队。

## 局限 / 注意点
不同引擎的硬件占用和质量差异较大；模型另有许可证。只能在获得授权时克隆他人声音，并需遵守 AGPL-3.0 和当地合规要求。
