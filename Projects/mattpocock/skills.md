# mattpocock/skills

## 一句话说明
一组面向真实软件工程任务的小型、可组合 Agent Skills，强调保留工程师控制权。

> 使用方式依据仓库当前 README 核对于 2026-09-28；这不代表历史上榜当日的 README 版本。

## 它能做什么
- Skills 颗粒度小、可编辑、可组合
- 覆盖调试、测试、设计与实现等日常工程流程
- 支持 Claude Code 插件安装和 skills.sh/Codex 安装

## 怎么利用
按任务只安装需要的 Skills；Claude Code 可订阅只读插件更新，Codex 等宿主可复制 Skill 到项目后自行修改，并用真实任务验证效果。

## 实际例子
**官方示例：** 场景 → 给 Codex 增加工程 Skills。输入 → 当前项目。操作 → 运行 `npx skills@latest add mattpocock/skills` 并选择 `setup-matt-pocock-skills` 与需要的能力。输出 → 项目内可编辑、可版本化的 Skill 文件。

## 适合谁
希望让 Coding Agent 遵循成熟工程方法、又不想被完整流程框架接管的开发者。

## 局限 / 注意点
同时安装 Claude 插件和可编辑副本会重复；Skill 质量仍取决于宿主执行与团队自己的测试。
