# paperclipai/paperclip

## 一句话说明
面向多 AI Agent 团队的开源管理与治理平台，把目标、组织架构、任务、预算、审批和审计放进同一控制面。

## 它能做什么
- 接入 Claude Code、Codex、Cursor、OpenClaw、HTTP/Bash 等不同 Agent。
- 用组织架构、目标继承、任务票据与 heartbeat 协调长期工作。
- 按 Agent/项目/目标追踪成本并设置预算硬停止。
- 提供审批、暂停、终止、审计日志和多组织隔离。

## 怎么利用
把多个已经能执行任务的 Agent 接入 Paperclip，为每个 Agent 指定角色、汇报关系和预算；用户只维护业务目标与任务，系统负责定时唤醒、分派、留痕和成本控制。

## 实际例子
**场景 →** 用多 Agent 推进一个 AI 笔记产品。 **输入 →** “做到 100 万美元 MRR”的公司目标、代码仓库，以及 CEO/CTO/工程/设计/营销 Agent。 **操作 →** 自托管 Paperclip，建立组织图、审批策略和月度预算，再把功能任务交给工程 Agent 并由管理 Agent复核。 **输出 →** 可追踪的任务结果、审批记录、执行日志和每个 Agent 的成本。

```bash
curl -fsSLO https://paperclip.ing/install.sh
bash install.sh
```

## 适合谁
同时管理多种 Coding Agent、需要预算与审计的 AI 产品团队或个人开发者。

## 局限 / 注意点
它是控制面，不是 Agent 框架、聊天机器人或代码评审器；官方安装器要求 Node.js 24.11+。首次部署应审查安装脚本、权限、密钥范围和预算策略。
