# roboflow/supervision

## 一句话说明
模型无关的 Python 计算机视觉工具箱，把检测结果、标注绘制、跟踪、区域统计和数据集处理封装成可复用组件。

## 它能做什么
- 把 Ultralytics、Transformers、MMDetection 等模型输出统一为 Detections
- 用可组合 annotators 绘制框、标签、轨迹和区域结果
- 加载、拆分、合并并导出 COCO、YOLO、Pascal VOC 等数据集
- 构建目标跟踪、计数、区域与实时视频分析流程

## 怎么利用
官方 Quickstart：`pip install supervision`，用任意检测模型对图片推理并转换成 `sv.Detections`；再用 `BoxAnnotator` 等组件把结果绘制到图像，输出标注图或继续统计。

```bash
pip install supervision
```

## 适合谁
构建目标检测、分割、跟踪和视频分析应用的计算机视觉工程师。

## 局限 / 注意点
- 需要 Python 3.10+；它提供后处理与可视化积木而不是训练好的通用模型，模型准确率、可选连接器和实时性能仍需单独验证。
