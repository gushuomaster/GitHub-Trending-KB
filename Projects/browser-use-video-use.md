# browser-use/video-use
## 项目定位
让 Coding Agent 参与视频编辑的开源工具。
## 核心功能
把视频编辑工作流暴露给 Coding Agent，以代码/Agent 驱动方式完成视频处理与编辑任务。
## 主要优点 / 特点
Agent-first 的视频编辑思路；Python 实现；把传统 GUI 视频操作转为可自动化工作流。
## 典型使用场景
自动化视频编辑、Coding Agent 视频工作流、批量内容处理。
