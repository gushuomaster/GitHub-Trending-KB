# ConardLi/garden-skills

## 一句话说明
汇集可安装的生产型 Agent Skills，覆盖网页设计、演示视频、图像生成、知识库检索和文章排版等任务。

## 它能做什么
- 提供网页设计、Web 视频演示、motion showreel、GPT Image、知识库检索等技能。
- 支持 skills CLI、Claude 插件、固定版本 ZIP、手动复制和 Git submodule。
- 为部分技能附带案例画廊、模板、校验脚本和不可变发布包。

## 怎么利用
**官方安装示例 →** 执行 `npx skills add ConardLi/garden-skills -s web-design-engineer`，CLI 自动识别 Codex 等宿主并放入正确目录；随后让 Agent 按技能创建页面，输出可运行的设计实现。
