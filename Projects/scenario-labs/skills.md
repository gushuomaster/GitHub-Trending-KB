# scenario-labs/skills

## 一句话说明
为 Scenario MCP 和专业创作软件提供媒体生成、质量控制及工具操作的 Agent Skills 集合。

## 它能做什么
- 生成图像、视频、音频、纹理、天空盒、3D 与自定义模型。
- 在生成前选择模型和报价，并维持角色、品牌与资产一致性。
- 提供 Blender、Maya、ZBrush、Unreal、Unity、Godot、Roblox 等专家技能。
- 把验证、质量门和生产工作流写成可安装的角色化说明。

## 怎么利用
用 skills CLI 只安装当前任务所需的技能，配置 Scenario MCP 或对应本地创作软件，再向 Agent 提供资产需求、参考风格和输出约束。

## 实际例子
```bash
npx skills add scenario-labs/skills --skill scenario-image-generation
```
随后要求 Agent 生成一组保持同一角色和品牌配色的药水图标，先报价/选模，再经过一致性与质量检查输出资产。

## 适合谁
需要让 Agent 参与游戏、美术、3D 和多媒体生产的创意技术团队。

## 局限 / 注意点
Scenario 核心技能依赖其 MCP、账号和可能的付费调用；专家技能需要已安装且版本匹配的本地软件，不同平台覆盖不一。技能说明不能保证最终质量，庞大技能集应按职责挑选，不宜无差别全部安装。
