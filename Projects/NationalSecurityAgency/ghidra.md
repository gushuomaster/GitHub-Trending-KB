# NationalSecurityAgency/ghidra

## 一句话说明
跨平台的软件逆向工程框架，用于反汇编、反编译、程序结构分析与自动化脚本处理。

## 它能做什么
- 分析多种处理器指令集、可执行文件格式与调试信息
- 提供反汇编、反编译、函数图和交叉引用等交互式视图
- 支持无界面批处理，用脚本自动导入和分析样本
- 通过 Java、Python 脚本和扩展组件添加分析能力

## 怎么利用
官方安装流程：准备 JDK 25，下载并解压官方 release，运行 `ghidraRun`；把自己拥有或获授权分析的二进制导入项目，再结合反编译器与调用图定位函数行为。

## 关键命令
```bash
./ghidraRun
```

## 适合谁
进行恶意代码分析、固件研究、漏洞研究或兼容性分析的安全研究人员与软件工程师。

## 局限 / 注意点
- 必须先检查项目安全公告，升级时不要覆盖旧安装目录；未知二进制应放在隔离环境中处理，逆向第三方软件还需确认授权和适用法律。
