# abue-ammar/tinycast

## 一句话说明
纯原生 macOS 快捷启动器，用一个全局热键搜索应用、文件、剪贴板、命令和日常工具，并兼容真实 Raycast 扩展。

## 它能做什么
- 模糊搜索并启动、聚焦或退出应用，支持全局与按应用快捷键
- 搜索指定文件夹、管理剪贴板历史、词典、计算器和 Quicklinks
- 运行 Apple Shortcuts、自定义 shell 命令、代码片段和窗口管理动作
- 以 SwiftUI/AppKit 原生渲染 Raycast 扩展，不含 Electron 与遥测

## 怎么利用
官方下载流程：安装最新 release，授予 Accessibility 等所需权限，设置全局热键；按下热键输入应用名、文件或命令，选择结果后直接启动、粘贴或执行。

## 适合谁
希望用轻量原生启动器替代多套 macOS 效率工具的个人用户与开发者。

## 局限 / 注意点
- 要求 macOS 26+；剪贴板历史、辅助功能和自动化权限会接触敏感内容，自定义 shell 命令也继承用户权限，使用前应审查配置与扩展。
