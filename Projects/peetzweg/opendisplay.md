# peetzweg/opendisplay

## 一句话说明
把 iPhone、iPad 或闲置 Mac 变成 Mac 的真实扩展显示器，支持 USB/Wi‑Fi、Retina 和触控输入。

## 它能做什么
- 创建 macOS 可识别和排列的虚拟扩展显示器
- 通过 USB 的 usbmuxd 或 Bonjour Wi‑Fi 低延迟传输
- 用 VideoToolbox H.264/HEVC 编码并支持 HiDPI
- 将点击、拖动和双指滚动回传到主 Mac

## 怎么利用
官方 Quickstart 场景：在主 Mac 安装发送端、iPad/iPhone 安装接收端；USB 连接或从 Bonjour 列表选择设备后，macOS 将其显示为可排列的第二屏。

```text
安装 Mac 发送端与 iOS/macOS 接收端后，通过 USB 或 Bonjour 配对。
```

## 适合谁
希望把闲置 Apple 设备变为扩展屏的 Mac 用户和开源显示技术开发者。

## 局限 / 注意点
- 依赖 macOS 与 Apple 设备版本，性能受编码器、Wi‑Fi 和线缆影响；这是社区虚拟显示方案，系统升级可能改变驱动或权限兼容性。
