# sherlock-project/sherlock

## 一句话说明
Sherlock 是用户名 OSINT 命令行工具，可把一个或多个用户名批量检查到 400 多个社交网络，并导出命中的公开账号链接。

## 它能做什么
- 一次检查一个或多个用户名在数百个社交网站上的存在情况。
- 支持按站点过滤、代理、超时、相似用户名占位符和 NSFW 站点选项。
- 可把结果保存为文本，并导出 CSV、XLSX 或 JSON。

## 怎么利用
安装 `sherlock-project` 后执行 `sherlock user123`；工具逐站点检查公开用户名并把命中 URL 写入 `user123.txt`，再由调查者逐条打开核验是否属于目标对象。

## 实际例子
**官方用法 →** 安装 `sherlock-project` 后执行 `sherlock user123`；工具逐站点检查公开用户名并把命中 URL 写入 `user123.txt`，再由调查者逐条打开核验是否属于目标对象。

```bash
pipx install sherlock-project
sherlock user123
```

## 适合谁
进行合法公开信息检索、品牌账号排查或安全调查初筛的 OSINT 与安全人员。

## 局限 / 注意点
只能以用户名为线索，不能直接按真实姓名、邮箱或手机号确认身份；同名账号和站点响应差异会产生误报，输出只是线索而不是身份结论。README 还提示部分第三方 ParrotOS/Ubuntu 24.04 包存在问题。
