# flutter/flutter

## 一句话说明
用一套 Dart 代码构建 iOS、Android、Web、Windows、macOS 和 Linux 应用，并在开发中通过热重载快速迭代界面。

**官方描述：** Flutter makes it easy and fast to build beautiful apps for mobile and beyond

## 它能做什么
- 以 Material、Cupertino 和自定义 Widget 构建像素级界面。
- 将 Dart 编译到移动端机器码、Web 的 JavaScript/WebAssembly 及桌面目标。
- 通过 stateful hot reload 保留应用状态并即时查看代码修改。
- 用 packages、FFI 和 platform channels 调用生态包或原生平台能力。

## 怎么利用
输入产品界面、业务状态和目标平台，用 Dart/Widget 编写共享 UI 与逻辑；Flutter 编译到选定平台，在模拟器或真机调试，最后输出各平台安装包或 Web 构建。

## 实际例子
**官方终端教程 →** 输入一个新应用名，运行 `flutter create my_app`、进入目录并执行 `flutter run` 选择设备；输出可在模拟器或真机运行的应用骨架，修改 Widget 后可热重载查看结果。

## 关键命令
```bash
flutter create my_app
cd my_app
flutter run
```

## 适合谁
需要用一套代码交付移动端、Web 或桌面应用的产品团队与客户端工程师。

## 局限 / 注意点
需要安装 Flutter SDK 与各目标平台工具链；iOS 构建仍需 macOS/Xcode，平台插件和原生权限需要分别测试。
