# cjpais/Handy

## 一句话说明
跨平台、完全离线的语音转文字应用；按住快捷键说话，松开后将本机转录结果粘贴到当前应用。

## 它能做什么
- 在设备本地完成录音与语音识别。
- 把转录文本直接输入当前应用，并支持自定义快捷键。
- 提供 macOS、Windows、Linux 发行版和运行实例的命令行控制。

## 怎么利用
安装 Handy，授予麦克风与辅助功能权限并设置快捷键；在编辑器中按住快捷键口述一段说明，松开后得到直接粘贴的文字。

## 实际例子
**场景 →** 安装 Handy，授予麦克风与辅助功能权限并设置快捷键；在编辑器中按住快捷键口述一段说明，松开后得到直接粘贴的文字。

**输入 →** 麦克风语音、已设置的快捷键和当前编辑器光标位置。

**操作 →** 按住快捷键口述，松开后由 Handy 在本机完成转录并通过系统输入机制粘贴。

**输出 →** 直接出现在编辑器中的文本；音频无需发送到云端。

## 关键命令
```bash
brew install --cask handy
```

## 适合谁
需要离线听写、无障碍输入或隐私敏感语音转文字的个人用户和团队。

## 局限 / 注意点
首次运行需下载语音模型；转录质量受口音、噪声与硬件影响，Linux 还可能需要 wtype、xdotool 或 ydotool 等输入工具。
