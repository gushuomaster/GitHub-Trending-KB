## 怎么利用
只选择当前科研任务需要的数据库与分析 Skill，交给 Agent 完成检索、清洗和计算；最终保留查询条件、数据版本、代码与可复现输出供领域专家审核。

## 实际例子
**可推导用法：** 场景 → 查询某基因与疾病的已知证据。输入 → 基因名、疾病名和目标数据库。操作 → 安装相关生物医学 Skill，执行数据库检索并导出来源。输出 → 带引用的证据表和可复现查询记录。
