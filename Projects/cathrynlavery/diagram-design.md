# cathrynlavery/diagram-design

> 功能和用法按 2026-10-14 当前官方资料核对，不声称等同于历史上榜日版本。历史统计未保存时保持空值，不使用当前值补写。

## 一句话说明
让 Coding Agent 把系统关系、流程和数据结构绘成可直接打开的 HTML＋SVG 图，并按品牌样式控制版式。

## 它能做什么
- 提供架构、流程、时序、状态、ER、Sankey、甘特等 45 种图型（核对日 README），并可按品牌定制。
- 每种图型提供浅色、深色和完整编辑风格的静态变体。
- 可重绘 Mermaid、draw.io 或 Excalidraw，并按尺寸和细节要求输出。

## 怎么利用
输入组件、连接、事件顺序与品牌参考，Agent 选择合适图型并生成自包含 HTML＋SVG；在浏览器检查关系和标注后嵌入文档。

## 实际例子
**官方 Quickstart →** 输入“前端、后端、数据库、Redis 缓存组成的应用架构”；Agent 选择 architecture 类型并保存 HTML，输出可在浏览器直接打开的技术架构图。

## 适合谁
编写系统设计、技术文章、产品方案或演示材料，需要可定制专业图形的工程师与作者。

## 局限 / 注意点
图中事实仍取决于输入信息，生成后必须人工核对；它是设计 Skill，不是完整 GUI 绘图软件。
