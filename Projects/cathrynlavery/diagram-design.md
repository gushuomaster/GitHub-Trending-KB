# cathrynlavery/diagram-design

## 一句话说明
让 Agent 把系统关系和流程绘成自包含 HTML＋SVG 图，便于放进文档、网页或继续编辑。

**官方描述：** Editorial diagram design for Claude Code, Codex, GitHub Copilot, Factory Droid, and Pi. 42 diagram types. Self-contained HTML + SVG. No shadows. No Mermaid slop.

## 它能做什么
- 生成架构、流程、时序、状态、数据模型等多种图型。
- 提供浅色、深色和完整编辑风格的静态变体，无需构建步骤。
- 将 draw.io、Mermaid 或 Excalidraw 源图按指定格式、尺寸和细节重绘。

此前能力说明：让 Coding Agent 生成更专业的 HTML+SVG 技术图、架构图和流程图，而不是只给默认 Mermaid 风格。

## 怎么利用
输入组件、连接、事件顺序及品牌参考；由技能选择合适图型和视觉重点，输出能直接在浏览器打开的 HTML＋SVG 文件，人工核对图中关系后用于设计文档。

此前工作流说明：让 Coding Agent 生成更专业的 HTML+SVG 技术图、架构图和流程图，而不是只给默认 Mermaid 风格。

## 实际例子
**可推导用法 → 场景：** 给订单服务设计文档配图。**输入：** 前端、订单 API、库存库和支付回调之间的连接。**操作：** 要求 Agent 用 architecture 图型表达连接并提供浅色版本。**输出：** 自包含 HTML＋SVG 架构图；关系正确性由提供者复核。

**已有场景（可推导用法；具体命令及兼容性以本次核对为准）：**
场景：写系统设计文档 → 输入组件、数据流和视觉要求 → Agent 按 diagram-design 规则选择图型并生成自包含 HTML+SVG → 输出可直接放入文档或继续编辑的架构图。
