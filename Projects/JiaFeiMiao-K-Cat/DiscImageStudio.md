# JiaFeiMiao-K-Cat/DiscImageStudio

## 一句话说明
把图片编码为光盘物理层数据，使图案直接呈现在 CD、DVD 或单层 BD-R 盘面。

## 它能做什么
- 提供图层、抖动、伽马和亮度编辑以适配光盘约束。
- 导出 CD WAV+CUE/RAW、DVD ISO 与单层 BD-R ISO。
- 可在视觉图案之外附带普通文件，并用成品照片做校准。
- 实验性支持从应用直接流式刻录。

## 怎么利用
Windows 用户运行 GUI，导入图片、调整物理层预览与校准参数，选择目标介质并导出镜像，再用可靠刻录软件写入空白盘；Linux/macOS 可试用实验性 CLI。

## 实际例子
将单色标志导入图层编辑器，针对 DVD 调整抖动和亮度，导出 ISO 后先在可报废空白盘测试，再根据照片校准下一版。

## 适合谁
研究光盘可视图案、数据艺术、归档介质和物理编码的创作者与工程师。

## 局限 / 注意点
GUI 要求 Windows 10 2004+ 与 .NET 10；直接刻录仍属实验功能。效果受刻录机、介质和固件影响，应先用可报废盘测试；蓝光仅支持 25GB 单层 BD-R，不支持双层。许可证为 GPL-3.0-or-later。
