# obra/superpowers

> 功能和用法按 2026-10-13 当前官方资料核对，不声称等同于历史上榜日版本。历史统计未保存时保持空值，不使用当前值补写。

## 一句话说明
一套面向 Coding Agent 的软件开发方法论，把需求澄清、设计、计划、TDD、实现、评审和验证组织成自动触发的技能流程。

## 它能做什么
- 在编码前触发 brainstorming，澄清需求并确认设计。
- 生成细粒度计划，并可用 worktree 隔离实现。
- 通过 TDD、代码评审和完成前验证形成闭环。

## 怎么利用
按宿主安装插件后直接提出开发需求；技能会先完成设计与计划，再进入实现、测试和评审，并保存可复核的过程产物。

## 实际例子
**官方验证示例 →** 新会话输入 `Let's make a react todo list`；正确安装时会先自动触发 brainstorming，而不是立即写代码。

## 适合谁
希望 Coding Agent 遵守一致工程流程，并愿意为设计、测试和评审投入额外步骤的开发者或团队。

## 局限 / 注意点
流程约束较强，简单任务可能增加步骤和 token；不同宿主的插件、hook 与子 Agent 能力并不完全一致。
