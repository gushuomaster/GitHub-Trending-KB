# obra/superpowers

## 一句话说明
一套给 Coding Agent 使用的软件开发方法论与可组合 Skills，把“先设计、再计划、TDD、实现、评审、验证”变成自动触发的工程流程。

## 它能做什么
- 在编码前自动进入 brainstorming 与设计确认。
- 生成细粒度实施计划并用 worktree 隔离开发。
- 支持 subagent-driven development、TDD、代码评审和完成前验证。
- 支持 Claude Code、Codex、Cursor、Gemini CLI、OpenCode 等多种 Agent harness。

## 怎么利用
安装到你的 Coding Agent 后，正常提出开发需求；Superpowers 会自动触发相应 Skill，而不是让 Agent 直接跳到写代码。

## 实际例子
**场景 →** 新建 React Todo。 **操作 →** Codex/Claude Code 安装 Superpowers 后输入 `Let's make a react todo list`。 **结果 →** Agent 应先触发 brainstorming，确认设计后生成计划，再进入实现、测试和评审流程。

## 适合谁
希望 Coding Agent 遵守稳定软件工程流程的开发者与团队。

## 局限 / 注意点
流程约束较强，简单任务也可能增加步骤与 token 消耗；不同 Agent 的插件/Hook 能力并不完全一致。
