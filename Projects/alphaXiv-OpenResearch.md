# alphaXiv/OpenResearch

## 项目定位
Local-first 研究 Agent 工作区，把 Claude Code、Codex、OpenCode、Cursor 等 Harness 转成可运行文献、假设、实验和研究产物的自动研究系统。

## 核心功能 / 实现特点
- Rust/Cargo + 本地 UI，含 `agent-skills/`、`src/`、`ui/`、`demo/`、`SKILL.md`、`SYSTEM_PROMPT.md`。
- v0.2.x 新增 Cursor 一等 Harness、managed repositories 持久存储，并修复 OpenCode 大配置输出被 pipe 截断；9 月 13 日仍在修 experiment tree viewport。

## 主要优点
- 将 Agent 研究落实为可观察实验树、代码仓库和产物，而非单轮 Deep Research
- 多 Harness 兼容，近期对持久化、配置和 UI 状态持续 hardening
- 适合科研 Agent、自动实验和本地研究工作台

## 局限 / 注意点
- 仍在 0.2.x 快速迭代，Windows 处 beta，接口可能继续变化
- 自动研究的可信度仍依赖数据、基线、环境可复现性和人工判断

## 最近变化
- 首次上榜；今日 +304 stars。近三天连续发布 0.2.0/0.2.1 并扩展 Cursor Harness，社区已开始讨论单机 GPU 调度后端。
