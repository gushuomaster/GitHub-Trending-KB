# microsoft/vscode

## 一句话说明
开源 Code‑OSS 编辑器代码库，是 Visual Studio Code 产品的社区开发基础。

> 使用方式依据仓库当前 README 核对于 2026-09-28；这不代表历史上榜当日的 README 版本。

## 它能做什么
- 代码编辑、导航、理解与轻量调试
- 扩展模型和工具集成
- 公开路线图、月度迭代计划与社区贡献流程

## 怎么利用
普通用户安装 VS Code/Insiders；需要研究编辑器或做品牌化发行时，基于 Code‑OSS 构建并明确处理微软专有定制、许可和商标差异。

## 实际例子
**官方使用场景：** 场景 → 开发一个编辑器扩展。输入 → 扩展需求与 VS Code API。操作 → 在 VS Code 中创建扩展项目、运行 Extension Host 调试。输出 → 可打包扩展；若修改编辑器本体则向本仓库提交并跑对应测试。

## 适合谁
软件开发者、VS Code 扩展作者，以及研究或二次开发 Code‑OSS 的团队。

## 局限 / 注意点
Code‑OSS 不等同于微软分发版 VS Code；大型仓库构建成本高，API、遥测、Marketplace 与品牌许可需分别处理。
