# microsoft/markitdown

## 项目定位
将 PDF/Word/Excel/PPT/HTML 等转换为更适合 LLM/RAG 的 Markdown

## 优点
- 轻量
- 微软维护
- 易集成 RAG
- 支持插件/MCP

## 局限 / 注意点
- 目标不是高保真人工阅读排版；不可信输入需注意 I/O 安全
