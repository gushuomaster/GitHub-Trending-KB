# microsoft/markitdown

## 项目定位
将 PDF/Word/Excel/PPT/HTML 等转换为更适合 LLM/RAG 的 Markdown

## 优点
- 轻量
- 微软维护
- 易集成 RAG
- 支持插件/MCP

## 局限 / 注意点
- 目标不是高保真人工阅读排版；不可信输入需注意 I/O 安全

## 怎么利用
把 Office、PDF、HTML 或媒体文件转换为 Markdown，再送入 RAG、摘要或文本分析；不可信文件应在隔离环境处理。

## 实际例子
**可推导用法：** 场景 → 将 PPT 加入知识库。输入 → 产品培训 PPTX。操作 → 用 MarkItDown 转成 Markdown并切块。输出 → 保留标题与正文的可索引文本。
