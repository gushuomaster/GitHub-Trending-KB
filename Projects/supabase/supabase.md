# supabase/supabase

## 一句话说明
基于 Postgres 的开源开发平台，用数据库、认证、自动 API、实时订阅、函数和对象存储提供 Firebase 式后端体验。

## 它能做什么
- 提供托管或自托管的 Postgres 数据库与 Dashboard
- 用 GoTrue、JWT 和数据库策略处理用户认证与授权
- 自动生成 REST、GraphQL API，并广播数据库实时变更
- 提供 Edge Functions、文件存储以及向量与 Embedding 工具

## 怎么利用
官方工作流：在 Supabase Dashboard 创建项目和数据表，配置 Row Level Security 与认证提供商；前端通过自动生成的客户端 API 写入数据、上传文件并订阅变更，或在本地开发后迁移到托管环境。

## 实际例子

## 适合谁
需要快速构建 Postgres 后端、认证、实时数据和存储功能的 Web 与移动开发团队。

## 局限 / 注意点
- 它不是 Firebase 的一一映射；自托管需要维护 Postgres、网关、认证、实时和存储等多个服务，错误的 RLS、密钥暴露或迁移策略可能导致数据泄露与停机。
