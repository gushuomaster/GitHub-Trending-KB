# jordan-gibbs/hyperresearch

## 项目定位
Agent 驱动的研究知识库，让 Agent 抓取、检索、综合网络资料并沉淀为持久、可搜索的研究 Wiki。

## 核心功能 / 实现特点
- Python；围绕 research runs、sources、claims、verification 与持久知识库组织，目标不是一次性回答，而是持续积累可复用研究资产。

## 主要优点
- 把 Deep Research 与长期知识库结合
- 强调来源、claims 与验证门禁，比单纯网页总结更工程化
- 适合研究型 Agent 和 Obsidian/知识库工作流参考

## 局限 / 注意点
- Issue 曾暴露 CJK token 计数、citation-density、Semantic Scholar 429、claims ingest 路径等边界问题
- 研究质量仍依赖数据源可用性和 Agent 对证据的忠实处理

## 怎么利用

## 实际例子
**可推导用法：** 场景 → 持续跟踪本地 LLM 推理。输入 → 论文、项目文档和 benchmark。操作 → 多轮研究并记录来源与 claims。输出 → 可检索、带引用的专题 Wiki。
