# jordan-gibbs/hyperresearch

## 一句话说明
为 Codex 和 Claude Code 提供深度研究流水线，把多源检索、引文核验和研究成果沉淀为可复用本地知识库。

## 它能做什么
- 在宽度搜索、引用追踪和缺口补查中收集大量来源
- 逐句核验引用是否支持正文，并检查撤稿信息
- 聚类转载和衍生内容，避免把同源报道误当多方共识
- 将来源保存到 Markdown＋SQLite vault，并支持中断恢复

## 怎么利用
官方 Codex 流程：运行 `pip install hyperresearch && hyperresearch install . --target codex`，随后输入 `$hyperresearch <研究问题>`；管线建立来源库、核验引文并输出带证据的研究报告。

```bash
pip install hyperresearch

```

## 适合谁
需要大规模检索、引文核验和可复用研究资料库的研究者、分析师与写作人员。

## 局限 / 注意点
- 大规模研究需要网络、时间和模型额度；付费墙只能在合法开放副本可得时补全文本，自动报告仍需研究者复核范围、来源质量与结论。
