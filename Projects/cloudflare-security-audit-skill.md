# cloudflare/security-audit-skill
## 项目定位
面向 Coding Agent 的多阶段安全审计 Skill，核心价值是把发现结构化并加入独立验证步骤，而不是只让模型自由审查。
## 核心功能 / 实现特点
JavaScript；多阶段审计、机器可读 findings、独立 verification，适合嵌入 Agent/CI 安全流程。
## 主要优点
- Cloudflare 官方维护，企业基础设施厂商正式进入 Agent Skills 层。
- 把“发现”和“验证”分离，降低单次 LLM 判断直接成为结论的风险。
