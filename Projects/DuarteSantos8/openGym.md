# DuarteSantos8/openGym

## 一句话说明
Self-hosted gym & body-weight tracker.

## 它能做什么
- 在自己的服务器上规划训练、记录组数/体重/PR、查看肌肉训练与恢复状态，并从 FitNotes/Strong/Hevy 导入数据。
- 可作为实际工作流中的独立工具或 Agent 能力使用。

## 怎么利用
在自己的服务器上规划训练、记录组数/体重/PR、查看肌肉训练与恢复状态，并从 FitNotes/Strong/Hevy 导入数据。

## 实际例子
场景：把原有 Hevy/Strong 训练迁到自托管环境 → Docker Compose 启动 openGym → 导入历史数据 → 手机上按当天计划记录训练 → 输出进度曲线、PR、肌肉热图和恢复状态。
