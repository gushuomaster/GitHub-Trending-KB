# mihail911/modern-software-dev-assignments

## 一句话说明
Stanford CS146S《The Modern Software Developer》的作业仓库，为 2026 秋季课程提供可复现的 Python 学习环境与任务入口。

## 它能做什么
- 集中保存课程作业与配套材料
- 固定 Python 3.12 作为课程运行版本
- 用 Conda 创建隔离环境
- 用 Poetry 安装和锁定项目依赖

## 怎么利用
官方 Repo Setup：安装 Anaconda 后创建 `cs146s` Python 3.12 环境，激活环境并安装 Poetry，再在仓库根目录执行 `poetry install --no-interaction`，得到可运行课程作业的统一工作区。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方 Repo Setup：安装 Anaconda 后创建 `cs146s` Python 3.12 环境，激活环境并安装 Poetry，再在仓库根目录执行 `poetry install --no-interaction`，得到可运行课程作业的统一工作区。

## 适合谁
选修或自学 Stanford CS146S 课程、需要统一 Python 作业环境的学习者。

## 局限 / 注意点
- 它是特定学期课程作业库而非通用开发框架；任务与依赖会随授课进度变化，使用者应遵守课程学术诚信要求，不能把生成式工具答案当成个人完成。
