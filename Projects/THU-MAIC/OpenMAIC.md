# THU-MAIC/OpenMAIC

## 一句话说明
把主题或课程资料转成多 Agent 互动课堂，自动生成教师、学生、课件、讨论和可导出的教学内容。

## 它能做什么
- 由多个教师/学生 Agent 围绕课程主题讲解和提问
- 从文档生成大纲、幻灯片、白板与互动内容
- 支持课堂内针对任意幻灯片元素继续追问
- 可编辑课程并导出离线课堂或 MP4

## 怎么利用
官方典型流程：输入课程主题或上传资料，选择模型和课堂配置，系统生成大纲与角色后启动互动讲授；教师可继续编辑幻灯片并导出课堂。

## 实际例子

## 适合谁
需要快速制作互动课程、AI 教师演示或可导出教学内容的教师和教育产品团队。

## 局限 / 注意点
- 课程事实取决于模型和解析质量，发布前必须由教师核对；自托管涉及模型密钥、文档上传和渲染服务，需及时安装安全更新。
