# BuilderIO/agent-native

## 一句话说明
用于构建 agentic 应用的 TypeScript 框架，让 Agent 成为应用架构中的原生参与者，而不是外挂聊天窗口。

## 它能做什么
- 在 TypeScript/React 应用中组织 Agent 行为与 UI。
- 把工具调用、应用状态和用户交互连接起来。
- 为 Agent-first 产品提供可复用应用框架。

## 怎么利用
把 Agent 能执行的业务动作封装为应用能力，再让前端把 Agent 的状态和结果直接呈现给用户，适合构建交互式 AI 产品。

## 实际例子
**可推导用法：** 场景 → 做一个 AI 内容后台。输入 → 用户给出“生成并发布产品页”的目标。操作 → Agent 调用应用内工具生成内容、更新页面状态并等待确认。结果 → 用户在同一 React UI 中看到并确认 Agent 的修改。

## 适合谁
React/TypeScript AI 应用开发者、Agent 产品团队。

## 局限 / 注意点
框架较年轻，快速迭代可能带来 API 与架构迁移成本。
