# BuilderIO/agent-native

## 一句话说明
用 TypeScript 构建带专用 UI 的 Agent 应用，让 Agent 与界面共享动作、数据和应用状态，而不是依赖模拟点击。

## 它能做什么
- 把业务能力定义为 UI 与 Agent 共用的 Action
- 让 Agent 读取当前页面、选中记录等应用状态
- 内置聊天、权限、记忆、自动化与 Agent Team 能力
- 通过 HTTP、MCP、A2A、CLI 等入口复用同一动作层

## 怎么利用
官方 Quick Start：运行 `npx --yes @agent-native/core@latest create my-agent --standalone --template chat` 创建应用；定义带 Zod schema 的 `hello` Action 后，Agent 将其作为工具调用，React UI 用同一函数渲染结果。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方 Quick Start：运行 `npx --yes @agent-native/core@latest create my-agent --standalone --template chat` 创建应用；定义带 Zod schema 的 `hello` Action 后，Agent 将其作为工具调用，React UI 用同一函数渲染结果。

## 适合谁
希望让 Agent 与业务 UI 共享数据、动作和审批界面的 TypeScript 产品团队。

## 局限 / 注意点
- 框架仍快速迭代，API 和应用结构可能变化；共享 Action 需要严格设计鉴权、输入校验和副作用审批，否则 UI 与 Agent 会同时扩大业务写权限。
