# pacifio/atlas

## 一句话说明
面向 Coding Agent 的源代码工作台，把每次提交关联到会话、提示词、工具调用和推理上下文。

## 它能做什么
- 在同一代码库并列运行 Claude、Codex 与 ACP 兼容 Agent
- 把 Agent 检查点与 Git commit 关联，回看每次变更的上下文
- 在设备本地共享长期记忆和 Markdown 知识
- 用 @ 引用文件、符号、分支与提交，为 Agent 精确提供上下文

## 怎么利用
官方工作流：安装桌面应用并打开 Git 仓库，为同一代码库启动不同 Agent；每次检查点记录为关联提交，可在审阅变更时追溯提示与工具调用，也可切换 Agent 而不必重新解释项目。

## 适合谁
需要并行使用多个 Coding Agent、又希望保留提交级来源追踪的软件团队。

## 局限 / 注意点
- 官方说明支持 macOS 和 Windows，Linux 尚未充分测试；`.atlas` 中的本地 SQLite 默认不进 Git，跨设备同步需另行设计，并行 Agent 仍会产生合并冲突和审阅负担。
