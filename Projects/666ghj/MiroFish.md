# 666ghj/MiroFish

## 一句话说明
把新闻、政策草案或故事等种子材料转成多 Agent 社会模拟，用群体互动探索可能的后续轨迹。

## 它能做什么
- 从种子材料提取实体、关系和个体/群体记忆
- 创建具有独立人格、长期记忆和行为逻辑的大量 Agent
- 在模拟运行中注入变量并观察宏观涌现
- 生成预测报告和可交互的平行数字世界

## 怎么利用
官方工作流：上传舆情分析、政策材料或小说文本，再用自然语言描述要推演的问题；系统构建关系图并运行多 Agent 互动，输出演化过程和详细报告。

## 适合谁
研究社会模拟、舆情推演或创作分支剧情的研究者与决策支持团队。

## 局限 / 注意点
- 模拟结果高度依赖输入、角色设定和模型偏差，不能当作真实世界概率预测；大规模 Agent 运行还会消耗大量模型额度与计算资源。
