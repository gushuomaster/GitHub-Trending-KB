# patchy631/ai-engineering-hub

## 一句话说明
把 LLM、RAG、Agent、OCR、语音和 MCP 的真实示例按难度整理成可运行教程，便于从单组件原型逐步学习复杂 AI 系统。

## 它能做什么
- 包含本地 OCR、聊天界面与基础 RAG 等入门项目。
- 提供 Agentic RAG、多 Agent、语音、品牌监控等进阶示例。
- 覆盖 MCP、向量数据库、多模态与部署组合。

## 怎么利用
选择 `simple-rag-workflow` 或 `local-chatgpt` 子目录，阅读该项目 README、安装其依赖并准备指定模型或服务，输入文档或问题后输出可运行的 RAG/聊天原型。

## 实际例子
**场景 →** 选择 `simple-rag-workflow` 或 `local-chatgpt` 子目录，阅读该项目 README、安装其依赖并准备指定模型或服务，输入文档或问题后输出可运行的 RAG/聊天原型。

**输入 →** 选定子项目要求的文档、模型或 API 凭据，以及一组测试问题。

**操作 →** 进入相应 RAG 子目录，按其 README 安装独立依赖、建立索引并运行示例界面，再用测试问题核对检索与回答。

**输出 →** 可运行的文档问答原型、检索到的上下文和回答结果，供继续添加评测与防护。

## 关键命令
```bash
git clone https://github.com/patchy631/ai-engineering-hub.git
cd ai-engineering-hub
```

## 适合谁
希望通过可运行案例学习 RAG、Agent、语音、OCR 与 MCP 的 AI 工程师。

## 局限 / 注意点
各子项目依赖、许可证、模型和 API Key 不统一，教程版本可能随第三方服务变化；示例不等于具备生产安全、评测和运维能力。
