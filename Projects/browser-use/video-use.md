# browser-use/video-use

## 一句话说明
把视频剪辑流程封装给 Coding Agent，让 Claude Code、Codex 等直接从原始素材生成最终视频。

## 它能做什么
- 自动剪掉停顿/口头语并组织镜头。
- 添加字幕、调色、音频淡化和动画 overlay。
- 让 Agent 先分析素材、提出剪辑方案，再执行并检查输出。

## 怎么利用
把原始视频素材放进工作目录，在支持该工作流的 Coding Agent 中描述目标视频；Agent 分析素材并生成剪辑计划，确认后自动处理。

## 实际例子
**场景 →** 把多段产品口播剪成发布视频。 **输入 →** 5 段原始口播。 **操作 →** 对 Claude Code/Codex 说 `edit these into a launch video`。 **结果 →** Agent 完成剪辑并在 `edit/final.mp4` 输出成片。

## 适合谁
短视频创作者、开发者营销团队、需要批量视频自动化的人。

## 局限 / 注意点
自动剪辑不等于人工创意导演；复杂叙事、版权素材、字幕准确性和最终审美仍需人工复核。
