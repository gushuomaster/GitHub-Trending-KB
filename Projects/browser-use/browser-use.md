## 怎么利用
为 Agent 提供隔离浏览器和明确网站范围，让它按步骤点击、输入、滚动和提取；登录、上传、提交或购买等动作保留人工确认。

## 实际例子
**可推导用法：** 场景 → 汇总三家供应商公开报价。输入 → 产品规格和供应商页面。操作 → Agent 逐站搜索并抽取价格、库存和链接。输出 → 带来源的结构化比较表。
