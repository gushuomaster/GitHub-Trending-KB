# browser-use/browser-use

## 一句话说明
让 LLM 通过 Python、CLI 或云端 Agent 操作浏览器，完成导航、点击、输入、提取和多步骤网页任务。

**当前官方描述：** Agents that use the browser.

## 它能做什么
- 提供浏览器 Agent 抽象，把自然语言目标转成浏览器动作。
- 可控制本地、云端或通过 CDP 连接的现有浏览器。
- 提供可扩展工具、会话配置、托管基础设施和 Python 集成。

## 怎么利用
选择本地或托管浏览器，配置模型密钥与允许访问的网站；将任务交给 Agent，观察动作与中间状态，对提交、上传或购买等动作保留人工确认。

## 实际例子
**官方 Python Quickstart →** 安装 `browser-use`、配置 OpenAI API Key，再创建带任务说明的 Agent；运行后得到浏览器执行轨迹与任务结果。

## 关键命令
```text
uv add browser-use
```

## 适合谁
开发网页研究、数据录入、回归检查或个人助理型浏览器 Agent 的 Python/AI 工程人员。

## 局限 / 注意点
生产稳定性受登录态、CAPTCHA、代理、页面变化和资源占用影响；涉及账户、付款或数据提交时需要权限边界和人工复核。
