# stablyai/orca

## 一句话说明
用桌面工作台同时管理多个编码 Agent，并把每个任务隔离在独立 Git worktree 中，方便比较、批注和合并结果。

## 它能做什么
- 在独立 worktree 中并行运行任意 CLI 编码 Agent
- 从桌面或手机监控、继续和接收任务通知
- 直接比较 AI diff、批注并把反馈送回 Agent
- 集成 GitHub、Linear、远程 SSH 与浏览器元素选择

## 怎么利用
官方场景：把同一功能提示发送给五个 Agent，每个 Agent 在独立 worktree 实现。输入 → 仓库和需求；操作 → 并行运行、比较 diff、在候选改动上批注；输出 → 选中的实现被合并回目标分支，其余实验保持隔离。

```bash
brew install --cask stablyai/orca/orca
```

## 适合谁
需要并行试验多个编码 Agent、比较实现并从桌面或手机管理任务的软件团队和个人开发者。

## 局限 / 注意点
需要桌面端及各 Agent 自己的账号或订阅；并行 worktree 消耗存储与算力且仍可能产生合并冲突。远程执行、浏览器控制与中继扩大权限面，应审查遥测和网络边界。
