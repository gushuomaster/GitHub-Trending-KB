# BuilderIO/agent-native
## 项目定位
用于构建 agentic 应用的 TypeScript 框架，强调让 Agent 成为应用架构中的原生参与者，而不是外挂聊天层。
## 核心功能与技术特点
TypeScript/React 生态；仓库规模较大，GitHub topics 明确包含 agent-native、agents、ai、react、typescript。2026-09-21 仍有 push，当前约 82 个 open issues，处于高活跃快速迭代期。
## 适用场景
Agent 驱动 Web 应用、交互式 AI 产品、需要把工具调用和 UI 状态结合的应用。
## 主要优点
产品层 Agent 框架定位清晰；与前端生态贴近；社区热度快速增长。
## 局限 / 注意点
框架仍年轻、Issue 数较高；快速演进可能带来 API 稳定性和架构迁移成本。
## 为什么值得记录
代表 Agent 从 CLI/后台执行器进入应用原生架构层。
