# punkpeye/awesome-mcp-servers

## 一句话说明
awesome-mcp-servers 是社区维护的 MCP Server 索引，按能力、语言、运行范围和平台标记帮助用户寻找可接入的工具服务。

## 它能做什么
- 按文件、数据库、云、开发工具等分类浏览服务器。
- 用语言、部署范围和操作系统标记筛选实现。
- 链接到客户端、框架、教程和独立远程服务器清单。

## 怎么利用
场景：为 Agent 寻找 PostgreSQL MCP。按数据库分类筛选候选项，逐个打开源仓库核对安装、权限和维护状态，再在隔离环境配置只读凭据并测试工具输出。
