# SnailSploit/Claude-Red

## 一句话说明
为 Claude Skills 系统整理授权红队与渗透测试方法，把不同攻击面的步骤、工具和升级路径封装成按需加载的 SKILL.md。

## 它能做什么
- 覆盖 Web、身份、Active Directory、无线、云、移动与漏洞开发等类别
- 根据对话触发按需加载，避免把全部安全知识塞进上下文
- 支持整库安装、稀疏检出单个类别或把特定 Skill 作为 Claude Code 系统文件

## 怎么利用
官方 Quickstart：将仓库克隆到 `~/.claude/skills/claude-red`；在明确授权的测试中提到 SQL 注入等目标时，Claude 加载相应 Skill，给出方法、工具与检查顺序。

git clone https://github.com/SnailSploit/claude-red ~/.claude/skills/claude-red

## 适合谁
在书面授权范围内做红队、漏洞研究、CTF 训练或安全教学的从业者。

## 局限 / 注意点
- 内容面向进攻安全，只能用于书面授权的环境、CTF 或自有系统；Skill 不能替代范围控制、人工审批和审计，也无法保证模型建议安全或正确。
