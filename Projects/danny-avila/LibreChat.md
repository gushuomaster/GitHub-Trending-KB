# danny-avila/LibreChat

## 一句话说明
可自托管的多模型 AI 对话与 Agent 平台，把模型提供商、工具、文件检索和多用户权限集中到一个 Web 界面。

## 它能做什么
- 在统一会话界面接入多家模型提供商并管理预设
- 创建 Agents 与子 Agent，并通过 MCP 或其他工具执行任务
- 提供 Code Interpreter、Artifacts、文件搜索与 RAG 工作流
- 用细粒度权限、用户管理和身份认证支持团队部署

## 怎么利用
官方文档流程：通过 Docker 部署并配置模型提供商，创建 Agent 后只授予任务所需的 MCP 工具与可选 Code Interpreter；用户在 Web UI 提问，Agent 调用工具并返回答案或生成物。

## 实际例子
**资料中的具体工作流：** 官方文档流程：通过 Docker 部署并配置模型提供商，创建 Agent 后只授予任务所需的 MCP 工具与可选 Code Interpreter；用户在 Web UI 提问，Agent 调用工具并返回答案或生成物。

## 适合谁
希望自托管多模型聊天、工具型 Agent 与团队访问控制的平台工程团队。

## 局限 / 注意点
- 多服务部署、模型凭据和升级维护成本较高；代码执行、MCP 工具与文件访问会扩大攻击面，必须显式配置沙箱、权限和访问控制。
