# vastsa/PI-Desktop

## 项目定位
Local-first AI Coding Agent 桌面工作区，统一模型、项目、会话、权限、Review、Skills/MCP/Subagents/Plugins。

## 核心功能 / 实现特点
- Electron/TypeScript 前端 + Rust host core；pi Agent Harness；插件可贡献 tools/commands/panels/themes/services/skills；支持 MCP 与独立上下文 Subagents。

## 主要优点
- 不绑定单一编辑器或云账号，可接 OpenAI/Anthropic/兼容 API/Ollama/LM Studio
- Agent/Plan/Goal 三种审批边界设计清晰
- 本地权限层、Review 与长会话 checkpoint 对工程使用友好

## 局限 / 注意点
- 官方明确处于 Early Preview，API/扩展接口可能变化
- 近期提交非常密集且存在功能 revert，说明仍在快速打磨稳定性
