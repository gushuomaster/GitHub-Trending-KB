# asgeirtj/system_prompts_leaks

## 一句话说明
按厂商和产品整理主流聊天机器人、Coding Agent 与消费级 AI 产品的系统提示词，供研究者比较隐藏规则与工具约束。

## 它能做什么
- 保存多个厂商和产品的完整系统提示词与配套 Skills
- 按产品目录和最近变更记录追踪提示词迭代
- 提供可直接阅读、对比和引用的 Markdown 原文

## 怎么利用
官方引用案例：研究者可打开 OpenAI、Anthropic 等目录，逐段比较不同 Agent 如何规定搜索、工具调用与安全边界；《华盛顿邮报》也曾基于该库制作交互报道。

## 实际例子

## 适合谁
研究 Agent 行为、提示词治理和 AI 产品差异的研究者、记者与安全团队。

## 局限 / 注意点
