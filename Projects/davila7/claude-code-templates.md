# davila7/claude-code-templates

## 一句话说明
Claude Code 的 Agent、Commands、Hooks、MCP、Skills 和配置模板集合，并提供 CLI 统一安装与管理。

## 它能做什么
- 安装可复用 Agent、命令、Hooks 与 Skills。
- 接入 GitHub、PostgreSQL、Stripe 等 MCP。
- 统一配置并监控 Claude Code 工作环境。

## 怎么利用
在新项目中按任务一次安装需要的开发角色、测试命令和外部工具连接，让 Claude Code 开箱即用地获得团队约定能力。

## 实际例子
**场景 →** 新建前端项目。 **操作 →** `npx claude-code-templates@latest --agent development-team/frontend-developer --command testing/generate-tests --mcp development/github-integration --yes`。 **结果 →** Claude Code 同时获得前端开发角色、测试生成命令和 GitHub MCP。

## 适合谁
频繁使用 Claude Code、需要团队配置复用的开发者。

## 局限 / 注意点
第三方模板会改变 Agent 行为并可能获得工具权限，安装前应审查内容与 MCP 凭据范围。
