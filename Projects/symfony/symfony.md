# symfony/symfony

## 一句话说明
Symfony 是 PHP Web 框架及可独立复用的组件集合，为 HTTP、依赖注入、控制台命令、事件与应用结构提供成熟基础。

## 它能做什么
- 提供完整 Web 框架所需的路由、控制器、依赖注入与配置机制。
- 拆分出 Console、HttpFoundation、EventDispatcher 等可单独使用的组件。
- 支持通过 Composer 组合项目并接入测试、缓存、安全和消息等生态组件。

## 怎么利用
如果要开发 PHP API，可从 Symfony Skeleton 创建项目，定义路由与控制器、注入服务并返回 JSON；框架处理请求生命周期，最终输出可部署的 API 服务。

## 实际例子

## 关键命令
```bash
composer create-project symfony/skeleton my-project
cd my-project
symfony server:start
```

## 适合谁
构建 PHP Web 应用、API、后台服务或需要复用成熟 PHP 组件的工程团队。

## 局限 / 注意点
依赖 PHP 与 Composer 生态；组件选择和配置具有学习成本，生产部署仍需数据库、缓存、队列与 Web 服务器等外部设施。
