# xiaolai/the-craft-of-selfteaching

## 一句话说明
一本以 Python 编程为入口的开源自学教材，通过阅读、练习、写作和作品反馈训练“能够独立掌握下一门知识”的能力。

## 它能做什么
- 用 Notebook 和 Markdown 解释阅读方法、知识前置引用、刻意练习和注意力管理。
- 从值、流程控制、函数和容器逐步进入面向对象、测试驱动开发、正则与生成器等 Python 内容。
- 提供 JupyterLab、VS Code、Git 和 Python 官方教程的配套附录。
- 通过“如何证明真的读过”和 Pull Request 校对流程，引导读者用作品与反馈验证学习。

## 怎么利用
先按仓库附录安装 JupyterLab，再从前言和 Part 1 顺序打开 Notebook；每章边运行代码边完成自己的练习，把遇到的前置知识记录下来并继续检索。输入是章节、练习目标和个人代码，教材提供概念与方法，读者通过运行、修改和写作形成作品，最终得到可复查的学习记录与独立解决问题的能力。

## 实际例子
**官方阅读路径 → 场景：** 从零学习函数。**输入：** `Part.1.E.4.functions.ipynb` 及一个要实现的小函数。**操作：** 在 JupyterLab 中阅读并运行示例，修改参数与返回值，再继续学习参数、文档字符串和 TDD 章节；需要反馈时按仓库说明提交校对或作品。**输出：** 可执行 Notebook、自己编写的函数和一条能继续深入的学习路径。


## 适合谁
希望以编程训练通用自学能力的初学者，以及需要一套可执行阅读与刻意练习方法的自学者。
