# Tencent/WeKnora
## 项目定位
腾讯开源的 LLM 知识平台，把原始文档转为可查询 RAG、自治推理 Agent 与自维护 Wiki。
## 核心功能 / 实现特点
Go 主体；覆盖 embeddings、reranking、semantic/vector search、multi-tenant、Ollama/OpenAI 接入，并把 RAG 与 Wiki/Agent 合并为长期知识系统。
