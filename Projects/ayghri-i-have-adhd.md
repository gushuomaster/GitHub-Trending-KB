# ayghri/i-have-adhd

## 项目定位
约束 Coding Agent 输出方式，强制简洁、突出下一步动作的 Behavior Skill。

## 核心功能 / 实现特点
- 以 Skill/提示规则为主，重点在跨 Agent 安装与激活约定。

## 主要优点
- 单日热度暴增，规则极轻量
- 可跨多种 Coding Agent 复用
- 适合减少冗长回答与认知负担

## 局限 / 注意点
- 核心仍是提示/行为规范，技术壁垒较低
- 不同 Agent 的 skill 激活机制不一致，Hermes 文档曾出现适配误导
