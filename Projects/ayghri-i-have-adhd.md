# ayghri/i-have-adhd

## 项目定位
约束 Coding Agent 输出方式，减少冗余并突出下一步动作的 Behavior Skill。

## 核心功能 / 实现特点
- Python/Markdown/Skill 规则为主，重点是跨 Agent 的安装、发现和激活约定。

## 主要优点
- 规则轻量，传播和复用成本低。
- 能明显改变 Agent 输出风格。
- 是 Behavior Skill 这一类能力的典型样本。

## 局限 / 注意点
- 技术壁垒较低，核心仍是行为规范。
- 不同 Agent 的 Skill 路径与发现机制存在兼容成本。
