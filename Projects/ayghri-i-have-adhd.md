# ayghri/i-have-adhd

## 项目定位
用一组 Behavior Skill 规则约束 Coding Agent 输出，强制答案优先、缩短冗余并突出下一步动作。

## 核心功能 / 实现特点
- Python/Markdown/Skill 规则为主，核心在跨 Agent 的安装、发现、激活与输出协议。

## 主要优点
- 极轻量，几乎没有接入成本
- 传播力极强，是 Behavior Skill 这个类别的代表案例
- 可以直接作为团队输出规范的设计参考

## 局限 / 注意点
- 技术壁垒较低，价值主要来自规则设计
- 已有 Issue 讨论规则可能诱导过度因果归因、影响语言质量，以及 Windows hook 兼容问题
