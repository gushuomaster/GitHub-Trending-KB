# viarotel-org/escrcpy

## 一句话说明
在桌面上镜像并控制 Android 设备，提供键鼠映射、多设备批量操作、文件管理和可视化自动化。

**当前官方描述：** 📱 Display and control your Android device graphically with scrcpy.

## 它能做什么
- 基于 scrcpy 在独立窗口显示和控制 Android 屏幕。
- 支持触控、摇杆、滑动等键鼠映射，以及多设备同步输入。
- 集成截图、APK 安装、文件、终端、图像识别自动化和 MCP Copilot。

## 怎么利用
安装发行包并通过 ADB 连接一台或多台 Android 设备；在桌面界面配置映射或自动化步骤，执行后得到同步操作、截图或测试结果。

## 实际例子
**可推导用法 →** 连接多台测试机，配置同一登录流程的点击与输入步骤；批量运行并截图，输出各设备的执行结果供移动端回归检查。

## 关键命令
```text
从 Releases 页面安装对应系统版本
```

## 适合谁
需要桌面控制 Android、做多设备演示、手游键鼠映射或移动端批量测试的用户与测试人员。

## 局限 / 注意点
依赖 ADB、scrcpy 和设备调试权限；图像识别与批量操作可能因分辨率、系统弹窗和应用版本变化失效。
