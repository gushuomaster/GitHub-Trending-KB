# sveltejs/svelte

## 一句话说明
Svelte 是编译型 Web UI 框架，把包含 HTML、CSS 和 JavaScript 的声明式组件转换成精简、定向更新 DOM 的 JavaScript。

## 它能做什么
- 用 `.svelte` 单文件组件组合标记、逻辑和作用域 CSS。
- 通过 `$state`、`$derived`、`$effect` 等 runes 表达细粒度响应式状态和副作用。
- 既可渐进嵌入现有页面，也可配合 SvelteKit 构建带路由、SSR、CSR 和预渲染的完整应用。

## 怎么利用
官方入门：运行 `npx sv create` 创建项目，在 `.svelte` 组件中声明状态、按钮事件和样式；开发时由 Vite 热更新，构建时编译为浏览器执行的优化模块。

## 实际例子
**官方资料中的工作流 →** 官方入门：运行 `npx sv create` 创建项目，在 `.svelte` 组件中声明状态、按钮事件和样式；开发时由 Vite 热更新，构建时编译为浏览器执行的优化模块。

## 关键命令
```bash
npx sv create
```

## 适合谁
构建交互组件、渐进式前端或 SvelteKit 全栈应用的 Web 开发者。

## 局限 / 注意点
Svelte 仓库本身主要提供 UI 编译器；完整路由、数据加载和部署通常需要 SvelteKit。Svelte 5 runes 与旧版语法并存，迁移项目需核对兼容性和第三方组件版本。
