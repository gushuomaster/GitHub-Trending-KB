# anthropics/skills

## 一句话说明
Anthropic 发布的 Agent Skills 示例与生产级文档技能参考库。

> 使用方式依据仓库当前 README 核对于 2026-09-28；这不代表历史上榜当日的 README 版本。

## 它能做什么
- 以 SKILL.md、脚本和资源封装可重复任务
- 覆盖创意、测试、MCP、企业沟通等场景
- 包含 Claude 文档、PDF、PPTX、XLSX 能力的参考实现

## 怎么利用
选择一个与任务相近的 Skill，阅读其说明、脚本和依赖后在隔离项目试运行；再复制为团队版本并加入品牌、权限和验收规则。

## 实际例子
**官方示例对应场景：** 场景 → 让 Agent 按公司模板创建演示文稿。输入 → 品牌规范、内容提纲和参考资源。操作 → 采用 PPTX Skill 的结构与脚本并替换组织规则。输出 → 可重复生成、可检查的演示文稿工作流。

## 适合谁
设计 Agent Skills、研究复杂生产技能结构或需要文档自动化的开发者。

## 局限 / 注意点
部分复杂文档技能为 source-available 而非 Apache 开源；示例需要按宿主、依赖与权限重新验证。
