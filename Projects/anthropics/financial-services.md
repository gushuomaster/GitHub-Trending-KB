# anthropics/financial-services

## 一句话说明
把投行、股票研究、私募、财富管理与财务运营流程封装成 Claude Agent、Skills、命令和数据连接器。

## 它能做什么
- 提供 Pitch、Market Researcher、Earnings Reviewer、Model Builder 等 Agent
- 覆盖 comps、DCF、LBO、三表、earnings 和 IC memo 等任务
- 同时支持 Cowork 插件与 Managed Agents API 部署
- 组合专业指令、子 Agent、MCP 数据源与审批流程

## 怎么利用
官方示例：安装 financial-analysis 核心插件和 earnings-reviewer，把已授权的财报、电话会记录与既有模型交给 Agent；它更新模型并起草 earnings note，最终成果交由合格分析师签核。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方示例：安装 financial-analysis 核心插件和 earnings-reviewer，把已授权的财报、电话会记录与既有模型交给 Agent；它更新模型并起草 earnings note，最终成果交由合格分析师签核。

## 适合谁
需要在严格人工签核下辅助投研、投行、私募、财富管理与财务运营的金融机构团队。

## 局限 / 注意点
- 仓库明确说明输出不构成投资、法律、税务或会计建议；Agent 不应执行交易、记账或批准开户，数据授权、模型幻觉、审计线索与合规责任仍由使用机构承担。
