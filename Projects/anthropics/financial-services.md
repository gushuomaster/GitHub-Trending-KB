# anthropics/financial-services

## 一句话说明
Anthropic 面向金融服务场景提供的 Agent、Skills 与数据连接器集合，用来把财报研究、估值、投行材料等专业流程交给 AI 辅助执行。

## 它能做什么
- 提供 Pitch Agent、Market Researcher、Earnings Reviewer、Model Builder 等工作流。
- 支持 comps、DCF、earnings 等金融分析任务。
- 把金融数据源、领域指令和可复用 Skill 组合成专业 Agent 工作流。

## 怎么利用
把财报、电话会记录和允许访问的数据源交给相应金融 Agent，让它先读取材料、更新模型与关键指标，再生成研究笔记草稿，最后由分析人员复核。

## 实际例子
**场景 →** 上市公司财报季研究。 **输入 →** 最新财报、电话会记录、已有估值模型。 **操作 →** 使用 Earnings Reviewer/相关 Skill 提取变化并更新分析。 **结果 →** 一份可供分析师复核的 earnings note 和模型变更。

## 适合谁
投研分析师、投行/PE 团队、金融 AI 应用开发者。

## 局限 / 注意点
示例不等于投资建议或可盈利策略；生产使用仍需处理数据授权、合规、模型幻觉与人工复核。
