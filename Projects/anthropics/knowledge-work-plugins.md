# anthropics/knowledge-work-plugins
## 项目定位
Anthropic 面向知识工作者的开源插件集合，把专业工作流程封装成可复用 Agent 能力。
## 核心功能 / 实现特点
Python 主体、Apache-2.0；插件化组织专业领域工作流，并通过自动化持续更新外部插件版本。

## 怎么利用
选择与岗位匹配的插件并先审查权限和外部数据访问，再把它嵌入研究、财务或运营的具体流程。

## 实际例子
**可推导用法：** 场景 → 分析一组基金材料。输入 → 授权文档和分析目标。操作 → 启用对应知识工作插件提取指标并交叉核对。输出 → 带来源的结构化分析草稿。
