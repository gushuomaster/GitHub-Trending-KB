# anthropics/claude-quickstarts

## 一句话说明
Claude Quickstarts 汇集可直接运行和改造的 Claude API 示例应用，帮助开发者从客服、数据分析、电脑与浏览器操作一直做到托管 Agent 集成。

## 它能做什么
- 提供客服 Agent、金融数据分析和 Computer Use 等完整示例，而不只是零散 API 调用。
- 演示 Playwright 浏览器工具、VNC 电脑工具以及 Python/TypeScript 最小 toolset 驱动。
- 展示自主编程双 Agent、Managed Agents 与 Slack、Linear、Sentry、CopilotKit 等系统的集成模式。
- 每个子项目带独立 README 和安装步骤，可作为定制应用的起点。

## 怎么利用
先选择最接近需求的子目录，配置 Claude API key，按该示例 README 安装依赖并运行；再替换知识库、工具或界面层，输出一个可继续开发的 Claude 应用。

## 实际例子
**官方 Customer Support Agent 示例 →** 输入企业知识库与客户问题，应用让 Claude 检索知识并生成客服回复；开发者可在此基础上接入自己的文档和工单流程。

## 关键命令
```bash
git clone https://github.com/anthropics/claude-quickstarts.git
cd claude-quickstarts/customer-support-agent
```

## 适合谁
需要验证 Claude API 产品思路、学习工具调用或快速搭建 Agent 原型的应用开发者和解决方案工程师。

## 局限 / 注意点
需要 Anthropic API key，各子项目的依赖、部署方式和成熟度不同；README 明确说明部分 browser/computer toolset 只是接口示例、不是生产代码。涉及电脑操作、消息平台或外部系统时仍须自行补充隔离、鉴权和人工审批。
