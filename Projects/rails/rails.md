# rails/rails

## 一句话说明
Rails 是面向数据库驱动 Web 应用的 Ruby 全栈框架，把 MVC、路由、ORM、视图和常用 Web 基础能力整合在统一约定中。

## 它能做什么
- 用 Active Record 将数据库行映射为包含业务逻辑的模型对象。
- 用 Action Pack 处理路由、控制器与 HTTP 请求响应。
- 用 Action View 渲染 HTML、邮件等模板，并可输出 JSON、XML 或 PDF 等响应。

## 怎么利用
如果要搭建一个内容管理站点，可安装 Rails、运行 `rails new myapp` 生成项目，定义模型和迁移后编写控制器与视图，最后通过内置服务器在本地验证完整 CRUD 流程。

## 关键命令
```bash
gem install rails
rails new myapp
cd myapp && bin/rails server
```

## 适合谁
希望快速交付数据库驱动网站、后台系统或 JSON API 的 Ruby 开发者与产品团队。

## 局限 / 注意点
Rails 强调约定优于配置，需要 Ruby 工具链并接受其项目结构；大型应用仍需自行设计缓存、部署、权限和前端交互。
