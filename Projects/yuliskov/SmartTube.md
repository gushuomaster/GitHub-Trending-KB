# yuliskov/SmartTube

## 一句话说明
为 Android TV 和电视盒子设计的开源媒体客户端，用电视遥控器友好的界面播放公共来源视频。

## 它能做什么
- 提供适合大屏与遥控器的浏览和播放界面
- 集成 SponsorBlock、倍速、直播聊天与按钮自定义
- 支持最高 8K、60fps、HDR，并且不依赖 Google Services

## 怎么利用
官方流程：在 Android TV 上从 F-Droid 或 GitHub Releases 安装，使用一次性连接码关联账户，再在电视端选择内容、调整倍速或启用 SponsorBlock。

## 适合谁
使用 Android TV 或电视盒子、重视开源播放器和遥控器体验的用户。

## 局限 / 注意点
- 不支持手机和平板，评论、语音搜索和投屏可能不如官方客户端稳定；README 披露过开发环境受恶意软件影响及公钥可能泄露，安装前应核对最新签名和安全公告。
