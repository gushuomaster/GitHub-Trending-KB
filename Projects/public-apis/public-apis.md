# public-apis/public-apis

## 一句话说明
按类别整理可公开使用的 API，并标注认证方式、HTTPS 和 CORS，帮助开发者快速找到原型或集成所需的数据源。

## 它能做什么
- 覆盖天气、金融、地理、健康、娱乐等大量 API 类别。
- 为条目记录认证、HTTPS 与 CORS 等接入信息。
- 通过贡献规范和自动检查维护社区目录。

## 怎么利用
开发天气原型时在 Weather 类别筛选支持 HTTPS、认证要求可接受的服务，打开其官方文档申请密钥并先做最小请求，输出可复核的响应样例后再接入应用。

## 实际例子
**场景 →** 开发天气原型时在 Weather 类别筛选支持 HTTPS、认证要求可接受的服务，打开其官方文档申请密钥并先做最小请求，输出可复核的响应样例后再接入应用。

**输入 →** 目标城市、是否允许 API Key，以及必须支持 HTTPS 的约束。

**操作 →** 在 Weather 分类比较条目的 Auth、HTTPS、CORS 标记，打开候选 API 的官方文档，申请凭据并按文档发送最小请求。

**输出 →** 一份可复核的天气 JSON 响应、错误处理样例和当前配额说明，供原型接入。

## 适合谁
寻找公开数据接口的 Web、移动端和原型开发者。

## 局限 / 注意点
这是社区维护的导航清单，不保证服务可用性、配额、准确性或合规；上线前必须回到各 API 官方条款与文档重新核验。
