# TNT-Likely/PanWatch

## 一句话说明
自托管 AI 盯盘助手，覆盖 A 股、港股、美股实时监控、持仓管理、技术分析和 TradingAgents 多 Agent 辅助决策。

## 它能做什么
- 实时市场监控和持仓管理。
- 技术分析、AI/多 Agent 分析。
- 支持多账户、模拟交易与通知推送。
- 后端 Python，前端独立 Web 应用。

## 怎么利用
在自己的服务器启动 PanWatch，把关注标的和持仓加入系统，配置行情数据与模型后持续监控；当条件触发时查看 AI 分析并接收通知。

## 实际例子
**场景 →** 同时监控 A/H/美股持仓。 **操作 →** `pip install -r requirements.txt` 后 `python server.py` 启动后端，录入持仓和关注列表并配置数据/模型。 **结果 →** 在自托管面板查看实时行情、组合盈亏和 AI 分析，并通过通知渠道接收提醒。

## 适合谁
个人投资者、量化研究者、希望自托管 AI 行情助手的开发者。

## 局限 / 注意点
AI 分析不是投资建议；真实交易前需独立验证数据延迟、策略可靠性、风险控制和券商/数据源合规性。
