# vercel-labs/json-render

## 一句话说明
受组件目录和 schema 约束的 Generative UI 框架，让模型生成可预测 JSON 界面，并在多种前端与文档运行时中渲染。

## 它能做什么
- 用 Zod schema 定义模型可用组件、属性与 Action
- 流式生成并逐步渲染符合规范的 JSON UI
- 同一目录适配 React、Vue、Svelte、Solid 和 React Native
- 扩展到 Next.js、PDF、Email、视频、终端和 3D 场景

## 怎么利用
官方 Quick Start：先用 `defineCatalog` 声明 Card、Metric、Button 及允许的 Action，再用 `defineRegistry` 绑定 React 实现；模型只生成目录内组件的 spec，`Renderer` 输出受约束的动态仪表盘。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方 Quick Start：先用 `defineCatalog` 声明 Card、Metric、Button 及允许的 Action，再用 `defineRegistry` 绑定 React 实现；模型只生成目录内组件的 spec，`Renderer` 输出受约束的动态仪表盘。

## 适合谁
构建受约束动态界面、跨端 Generative UI 或 AI 报表的前端与产品工程师。

## 局限 / 注意点
- schema 约束降低但不能消除不当交互，带副作用的 Action 仍需鉴权和确认；不同渲染器能力不完全一致，模型生成的布局、可访问性和业务正确性必须测试。
