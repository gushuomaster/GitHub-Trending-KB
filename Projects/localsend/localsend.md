# localsend/localsend

## 一句话说明
无需互联网或第三方服务器，在同一局域网中的 Windows、macOS、Linux、Android 和 iOS 设备间发送文件与消息。

## 它能做什么
- 自动发现附近设备并通过本地网络传输
- 使用 REST API 与 HTTPS 加密连接
- 支持多文件、目录和文本消息发送
- 覆盖桌面与移动平台，并提供 CLI

## 怎么利用
官方常见流程：在两台同一局域网设备上安装并打开 LocalSend，发送端选择接收设备和文件，接收端确认后直接通过局域网保存，不上传云端。


## 适合谁
需要在多平台设备间离线、安全直传文件的个人和团队。

## 局限 / 注意点
- 设备发现会受访客网络隔离、防火墙和 VPN 影响；默认依赖接收端确认，传输敏感文件时仍要核对设备名称和本地网络可信度。
