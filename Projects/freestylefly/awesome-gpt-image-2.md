# freestylefly/awesome-gpt-image-2

## 一句话说明
把 GPT Image 2/2.5 的社区案例、提示词和工业模板整理成可复用的 Prompt-as-Code 资产与 Agent Skill。

## 它能做什么
- 提供 500 多个带图像与完整提示词的案例库
- 按 UI、信息图、海报、电商等场景组织 20 多套结构化模板
- 用统一数据生成网站图库和 `gpt-image-2-style-library` Skill
- 支持复制提示词、按风格筛选和对比生成案例

## 怎么利用
官方 Skill 示例：执行 `npx skills add freestylefly/awesome-gpt-image-2 --skill gpt-image-2-style-library --agent claude-code codex --global --yes --copy`，再要求 Agent“为 Codex 生成信息图提示词”，输出可直接用于图像模型的结构化 prompt。

## 适合谁
需要复用图像提示词、建立批量图像生成模板或让 Agent 选择视觉风格的设计师、内容团队与开发者。

- 仓库整理了来自公开社区的素材，原始生成条件和准确模型 ID 有时无法验证；网站生成可能涉及第三方 API、登录和费用，需查看免责声明。
