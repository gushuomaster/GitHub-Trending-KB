# paperless-ngx/paperless-ngx

## 一句话说明
自托管的无纸化文档管理系统，把扫描件和电子文件做 OCR、归档、标记与全文检索。

## 它能做什么
- 从 consume 目录、扫描仪或邮件导入文档
- 用 OCR 将扫描 PDF 转成可搜索文本
- 按联系人、文档类型、标签与自定义字段组织档案
- 通过 Web UI 与 REST API 搜索、预览和自动化处理

## 怎么利用
官方 Docker 路线：用安装脚本生成 Compose 环境，启动服务后把发票或扫描件放入 consume 目录；系统执行 OCR 和归档，用户在 Web UI 中补充标签并通过全文搜索找回。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方 Docker 路线：用安装脚本生成 Compose 环境，启动服务后把发票或扫描件放入 consume 目录；系统执行 OCR 和归档，用户在 Web UI 中补充标签并通过全文搜索找回。

## 适合谁
希望在自有服务器归档家庭或小型组织扫描件、发票与往来文档的用户。

## 局限 / 注意点
- 官方警告文档内容以明文存储，不能部署在不可信主机；税务、身份等敏感材料必须配套磁盘/网络防护、访问控制、离线备份和恢复演练，OCR 结果也需抽查。
