# thedotmack/claude-mem

## 一句话说明
Persistent Context Across Sessions for Every Agent.

## 它能做什么
- 自动捕获 Agent 会话中的工具使用和观察，压缩成持久记忆，并在未来会话重新注入相关上下文。
- 可作为实际工作流中的独立工具或 Agent 能力使用。

## 怎么利用
自动捕获 Agent 会话中的工具使用和观察，压缩成持久记忆，并在未来会话重新注入相关上下文。

## 实际例子
场景：长期维护同一代码库 → 安装 claude-mem → 开发过程中自动记录决策、修复和上下文 → 下次打开 Claude Code/Codex 等 Agent 时检索并注入相关历史，减少重复解释。
