# ZuodaoTech/everyone-can-use-english

## 一句话说明
围绕“人人都能用英语”构建的开源学习资料与 Enjoy 应用，通过视频、电子书、闪卡和课程组织英语自我训练。

## 它能做什么
- 提供网页版 Enjoy 的视频、电子书、闪卡和课程入口
- 用浏览器扩展支持 YouTube 与 Netflix 学习
- 保存《人人都能用英语》书籍与“一千小时”训练资料
- 用 AI 辅助口语、语音和输入输出训练

## 怎么利用
官方入口：直接访问 Enjoy 网页版，选择视频、电子书、闪卡或课程训练；观看 YouTube/Netflix 时可安装 Enjoy Echo 浏览器扩展，把原生内容带入听读与复习流程。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方入口：直接访问 Enjoy 网页版，选择视频、电子书、闪卡或课程训练；观看 YouTube/Netflix 时可安装 Enjoy Echo 浏览器扩展，把原生内容带入听读与复习流程。

## 适合谁
希望用视频、电子书、闪卡与系统资料持续练习英语的中文学习者。

## 局限 / 注意点
- 学习效果依赖长期投入与主动练习，AI 反馈不能替代真人交流和专业语音指导；浏览器扩展支持范围有限，桌面新版在核对时仍标为即将发布。
