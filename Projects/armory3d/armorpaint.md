# armory3d/armorpaint

## 一句话说明
面向 3D 模型的 PBR 纹理绘制工具，开发者可从源码构建桌面、移动端或 WebAssembly 版本。

## 它能做什么
- 在 3D 模型表面绘制基于物理渲染的材质和纹理
- 提供 Windows、Linux、macOS、Android、iOS 和 WASM 构建目标
- 开放 C 源码与构建脚本，便于修改图形工作流

## 怎么利用
官方源码流程：克隆仓库后进入 `paint`，在 Linux 运行 `../base/make --run`，输出并启动本地构建；Windows 则生成 Visual Studio 工程后编译。

## 实际例子
**官方材料中的工作流：** 官方源码流程：克隆仓库后进入 `paint`，在 Linux 运行 `../base/make --run`，输出并启动本地构建；Windows 则生成 Visual Studio 工程后编译。

## 关键命令
```bash
git clone https://github.com/armory3d/armorpaint
cd armorpaint/paint
../base/make --run
```

## 适合谁
制作 3D PBR 材质、开发纹理绘制工具或需要从源码定制图形工作流的美术与图形工程师。

## 局限 / 注意点
- README 明确开发仓库可能不稳定；官方分发的预编译二进制是付费产品，自行构建需要对应平台编译器和依赖。
