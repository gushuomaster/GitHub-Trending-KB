# androoAGI/starnet

## 一句话说明
把多 Agent 的真实运行状态映射成像素空间站的本地优先桌面工作台。

> 使用方式依据仓库当前 README 核对于 2026-09-28；这不代表历史上榜当日的 README 版本。

## 它能做什么
- 每个 Agent 有独立 workspace、记忆和权限
- 房间、走廊与物件直接映射团队、交接和能力授权
- 支持多模型、消息渠道、定时任务、Night Shift 与可审计日志

## 怎么利用
先创建一个边界明确的 Agent 和工作区，再用房间与能力物件授予最小权限；稳定后添加专员和交接走廊，并审查每个离席动作和成本。

## 实际例子
**官方能力对应场景：** 场景 → 夜间整理仓库 Issue。输入 → 只读 GitHub 权限、Issue 列表和成本上限。操作 → 创建 triage Agent，启用 Night Shift 并限制只能分类和起草。输出 → 次日可复核的分类结果、草稿和完整行动日志。

## 适合谁
希望可视化编排本地多 Agent、同时保留权限和成本边界的个人或小团队。

## 局限 / 注意点
真实模型调用会产生费用；桌面隐喻不替代权限审计，多渠道连接和夜间自动化需严格限制。
