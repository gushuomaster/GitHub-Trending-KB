# hyprwm/Hyprland

## 一句话说明
独立实现、可高度定制的动态平铺 Wayland 合成器，在窗口布局之外提供动画、模糊、插件、规则和 IPC。

## 它能做什么
- 支持平铺、伪平铺、浮动、全屏、标签组和多种工作区布局。
- 提供动画、渐变边框、模糊、阴影与自定义曲线。
- 支持插件管理、窗口/显示器规则、热重载配置和 socket IPC。

## 怎么利用
按发行版文档安装 Hyprland，启动 Wayland 会话后编辑配置文件设置显示器、快捷键和窗口规则；保存即重载，输出按规则自动平铺的桌面。

## 实际例子
**场景 →** 按发行版文档安装 Hyprland，启动 Wayland 会话后编辑配置文件设置显示器、快捷键和窗口规则；保存即重载，输出按规则自动平铺的桌面。

**输入 →** 显示器布局、快捷键和按应用类名匹配的窗口规则。

**操作 →** 按官方 Quick Start 安装并进入 Hyprland 会话，在配置文件写入 monitor、bind 和 windowrule，保存触发即时重载。

**输出 →** 自动平铺到指定工作区的桌面、可重复快捷键和无需重启的配置结果。

## 适合谁
希望深度定制 Linux Wayland 工作区、窗口规则、动画和自动化的桌面用户。

## 局限 / 注意点
仅面向 Linux Wayland，更新活跃且插件与配置可能随版本变化；显卡驱动、登录管理器和桌面组件需按官方兼容文档配置。
