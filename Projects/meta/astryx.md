# meta/astryx

## 一句话说明
Astryx 是 Meta 开源的 React 设计系统，把 150 多个可访问组件、主题、模板和 CLI 统一起来，让设计师、开发者和 Coding Agent 使用同一套界面规范。

## 它能做什么
- 提供 150+ 个带 TypeScript 类型的可访问 React 组件与常用交互模式。
- 用 CSS 自定义属性实现品牌主题、暗色模式和七套可定制主题。
- CLI 可查询组件文档、生成模板、执行 codemod，并支持把组件源码 swizzle 到项目中接管。

## 怎么利用
在 React 19 项目安装 core、neutral theme、StyleX 和 CLI，导入预构建 CSS 并包裹主题 Provider；随后用 CLI 查询组件并组合表单或页面模板，输出符合统一主题的 React 界面。

## 实际例子
**官方入门 →** 在 React 19 项目安装 core、neutral theme、StyleX 和 CLI，导入预构建 CSS 并包裹主题 Provider；随后用 CLI 查询组件并组合表单或页面模板，输出符合统一主题的 React 界面。

## 关键命令
```bash
npm install @astryxdesign/core @astryxdesign/theme-neutral @stylexjs/stylex
npm install -D @astryxdesign/cli
```

## 适合谁
构建设计系统、React 产品界面或希望让 Coding Agent 遵循统一组件规范的前端与设计平台团队。

## 局限 / 注意点
项目当前处于 Beta，要求 React 19+；部分图表包仅有 canary 版本。贡献仓库还要求 Node 22+ 与 pnpm 11，API 和行为在稳定版前可能变化。
