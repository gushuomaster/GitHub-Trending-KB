# nab138/iloader

## 一句话说明
图形化 iOS/iPadOS 侧载工具，帮助用户安装 SideStore 或自有 IPA，并管理配对文件与开发证书。

## 它能做什么
- 自动安装 SideStore 或 LiveContainer＋SideStore 并放置配对文件
- 导入用户自己取得的 IPA
- 管理配对文件、开发证书和 App IDs
- 针对常见失败给出错误建议和可查看日志

## 怎么利用
官方流程：安装平台对应的 usbmuxd，连接 iPhone/iPad，打开 iloader 并登录 Apple ID，然后选择 Install SideStore 或 Import IPA；输出已签名并安装到设备的应用。

## 适合谁
需要在自己设备上安装自有 IPA、SideStore 或管理 iOS 配对与开发证书的高级用户和开发者。

## 局限 / 注意点
- 需要 Apple ID、USB 配对和平台驱动，签名有效期及可安装数量受 Apple 规则限制；只应侧载自己有权使用的应用。
