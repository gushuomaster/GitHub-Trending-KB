# Swordfish90/cool-retro-term

## 一句话说明
用 Qt/QML 模拟老式阴极射线管外观的终端模拟器，为命令行增加复古显示效果。

## 它能做什么
- 模拟绿色、琥珀、IBM DOS 等 CRT 配色和扫描效果
- 通过右键菜单调整字体、颜色与视觉特效
- 基于 qtermwidget 提供正常终端交互
- 在 Linux 与 macOS 运行并提供发行包

## 怎么利用
官方流程：从 Releases 下载 Linux AppImage 或 macOS dmg，启动后在上下文菜单选择配色、字体和 CRT 效果，再像普通终端一样运行 shell 命令。

## 适合谁
偏好复古视觉、仍需要正常 shell 交互的 Linux/macOS 命令行用户。

## 局限 / 注意点
- 主要价值是视觉效果而非终端新能力；只支持 Linux/macOS 且依赖 Qt6，高强度特效可能影响性能、可读性与无障碍体验。
