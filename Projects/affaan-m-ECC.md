# affaan-m/ECC

## 项目定位
跨 Coding Agent 的 Harness 性能优化系统，覆盖 Skills、Memory、Security、Orchestration、Testing 与持续学习。

## 核心功能 / 实现特点
- JavaScript/Node + 大量 skills/rules/hooks/commands；包含 AgentShield/GateGuard、memory MCP、harness audit、model routing 等。

## 主要优点
- 跨 Claude Code、Codex、OpenCode、Cursor、Gemini、Hermes 等生态复用
- v2.2.1 明确强化 GateGuard、安全与数据保护

## 局限 / 注意点

- 快速扩张带来兼容、性能和安全回归风险，需要选择性启用
