# manaflow-ai/cmux

## 一句话说明
Open source Ghostty-based macOS terminal with vertical tabs and notifications for AI coding agents.

## 它能做什么
- 在 macOS 里并行管理多个 Claude Code/Codex 等终端 Agent，会显示工作区、Git 分支、PR、端口和等待通知。
- 可作为实际工作流中的独立工具或 Agent 能力使用。

## 怎么利用
在 macOS 里并行管理多个 Claude Code/Codex 等终端 Agent，会显示工作区、Git 分支、PR、端口和等待通知。

## 实际例子
场景：同时跑 5 个 Coding Agent → 每个任务放到独立 cmux workspace/split → Agent 等待输入时 pane 高亮并进入通知面板 → 你直接跳到未读任务继续处理；还可用 `cmux ssh user@remote` 管远程 Agent。

## 适合谁
需要解决上述问题的开发者、工程团队或自托管用户。

## 局限 / 注意点
仅面向 macOS；大量并行 Agent 仍受机器资源、上下文和各 Agent 自身限制。
