# cathrynlavery/diagram-design

## 项目定位
为 Coding Agent 提供专业图表/架构图的设计 Skill，输出 HTML+SVG，并带可执行验证器。

## 核心功能 / 实现特点
- HTML+SVG + Python 验证脚本；CI 检查导入安全、几何规则、移动端渲染；支持 Mermaid/draw.io/Excalidraw 导入重绘。

## 主要优点
- 从提示模板继续演进为带验证器的可测试视觉语法
- 新增 Excalidraw 导入重绘能力与 waterfall 第 40 种可验证图表类型
- 对文档、架构设计和 Agent 生成图稳定性价值高

## 局限 / 注意点
- 不是完整交互式设计软件
- 视觉质量仍依赖 Agent 对布局规则的执行；README/素材曾出现文档一致性问题
