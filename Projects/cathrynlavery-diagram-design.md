# cathrynlavery/diagram-design

## 项目定位
为 Coding Agent 提供专业图表/架构图设计 Skill，并用验证器把视觉规则工程化。

## 核心功能 / 实现特点
- HTML+SVG + Python/self-check。
- 支持 Mermaid/draw.io/Excalidraw 导入重绘。
- CI 检查资源、安全、几何和兼容问题。

## 主要优点
- 不止是提示模板，而是可测试的视觉语法。
- 适合架构设计、技术文档和 Agent 自动制图。
- 对生成稳定性有明确验证层。

## 局限 / 注意点
- 不是完整交互式设计软件。
- 视觉质量仍取决于布局规则执行和验证覆盖率。
