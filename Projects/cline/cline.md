## 怎么利用
把 Cline 作为 IDE、CLI 或 SDK 中的 Coding Agent，为单个任务配置模型、工具与审批；让它修改代码并运行验证。

## 实际例子
**可推导用法：** 场景 → 在 VS Code 新增登录表单校验。输入 → 仓库和验收规则。操作 → Cline 查找组件、修改代码并跑测试。输出 → 可审查的 diff 与测试记录。
