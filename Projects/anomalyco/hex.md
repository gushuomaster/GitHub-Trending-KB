# anomalyco/hex

## 一句话说明
面向 macOS、Windows 和 Linux 的本地语音听写工具；按住快捷键说话，松开后自动在当前应用粘贴转录文本。

## 它能做什么
- 语音模型在本机运行，首次下载后音频无需离开设备。
- 支持按住说话、松开转录并粘贴到任意当前应用。
- 提供多平台稳定版、开发版和 Homebrew 安装。

## 怎么利用
安装并启动 Hex，等待首个语音模型下载完成；在邮件或编辑器中按住设定快捷键口述，松开后得到粘贴到光标处的文字。

## 实际例子
**场景 →** 安装并启动 Hex，等待首个语音模型下载完成；在邮件或编辑器中按住设定快捷键口述，松开后得到粘贴到光标处的文字。

**输入 →** 麦克风语音、当前邮件正文光标和 Hex 快捷键。

**操作 →** 按住快捷键说话，松开后由本地模型转录，Hex 将文本粘贴到当前应用。

**输出 →** 邮件草稿中的可编辑文字；首个模型下载完成后语音处理留在设备内。

## 关键命令
```bash
brew install --cask anomalyco/tap/hex
```

## 适合谁
希望在常用桌面应用中使用本地语音听写的 macOS、Windows 和 Linux 用户。

## 局限 / 注意点
需要麦克风和系统输入权限；准确率受模型、口音、噪声与硬件影响，Labs 功能为实验状态。
