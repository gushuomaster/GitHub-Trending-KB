# jquery/jquery

## 一句话说明
jQuery 为浏览器 DOM 查询、事件、动画和 AJAX 提供一致 API，适合维护传统网页或制作按需裁剪的兼容层。

## 它能做什么
- 选择和遍历 DOM 并修改内容。
- 统一事件绑定、AJAX 与效果 API。
- 通过构建参数排除 ajax、effects 等模块。

## 怎么利用
场景：维护旧站点的表单交互。选择表单元素、监听提交并用 `$.ajax` 发送数据，处理响应后更新页面提示；若不需要网络模块，可构建精简版本。
