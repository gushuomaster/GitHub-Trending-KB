# google/ax
## 项目定位
Google 开源的 Agentic orchestration runtime。
## 核心功能
为 Agent 工作负载提供开放的编排与执行运行时基础。
## 主要优点 / 特点
Go 实现；由 Google 维护；定位明确在 Agent 编排运行时层，而不是单一聊天应用。
## 典型使用场景
Agent 工作流编排、执行运行时、平台级 Agent 基础设施。
