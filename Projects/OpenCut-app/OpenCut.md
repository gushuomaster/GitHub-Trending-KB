# OpenCut-app/OpenCut

> 功能和用法按 2026-10-13 当前官方资料核对，不声称等同于历史上榜日版本。历史统计未保存时保持空值，不使用当前值补写。

## 一句话说明
开源视频编辑器项目；当前主仓库正在重写，日常剪辑应使用仍在运行的 classic 版本。

## 它能做什么
- 现有经典版保留在 `opencut-app/opencut-classic`，`opencut.app` 目前运行该版本。
- 重写规划包括 Rust 核心、Editor API、第三方插件、桌面/移动/浏览器，以及 MCP、无界面渲染和脚本页。
- 重写版提供 Web/API/desktop 开发入口，不能把规划能力视为已交付功能。

## 怎么利用
普通用户先访问 `https://opencut.app` 或查看 classic 仓库；参与新架构开发时，在主仓库使用 `proto use` 安装锁定工具，再用 `moon run web:dev` 和 `moon run api:dev` 启动开发服务。

## 实际例子
**可推导用法 → 场景：** 学习如何实现视频编辑工作台。**输入：** 自有短视频素材与剪辑需求。**操作：** 先用 classic 查看已实现的剪辑交互，再阅读重写版的 Web 和 Rust 核心组织方式。**输出：** 可用版本体验和对新架构的理解；不能依赖尚在规划的 MCP 或批量渲染交付任务。

## 适合谁
寻找开源剪辑工具，或研究视频编辑器架构的用户与开发者。

## 局限 / 注意点
主仓库处于重写阶段，当前并非完整稳定编辑器；外部贡献暂未全面开放。classic 与新版本的功能和安装方式需要分开核对。
