# yynxxxxx/Codex-X

## 一句话说明
面向 OpenAI Codex 桌面端和 CLI 的跨平台可视化管理工具，把提示词、Provider、会话、Skills、MCP 与 TOML 配置集中到 GUI。

## 它能做什么
- 分类、同步、导入和启停 Markdown 提示词模板
- 保存并切换官方登录或第三方 API Provider
- 搜索、同步、检查和删除本地 Codex 会话
- 可视化管理 Skills、MCP、config.toml 与 auth.json

## 怎么利用
官方工作流：安装对应平台版本，导入现有 Codex 配置；在 Provider 页面添加并检测 API，在 Skills/MCP 页面预览后启用所需扩展，保存前由应用自动备份配置，输出切换后的 Codex 会话环境。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方工作流：安装对应平台版本，导入现有 Codex 配置；在 Provider 页面添加并检测 API，在 Skills/MCP 页面预览后启用所需扩展，保存前由应用自动备份配置，输出切换后的 Codex 会话环境。

## 适合谁
同时维护多套 Codex Provider、提示词、会话、Skills 和 MCP 配置的重度用户。

## 局限 / 注意点
- 第三方管理层需持续追随 Codex 配置和协议变化；它会读取或写入 auth.json、API Key、会话和配置，必须保护本地数据库与备份，永久删除会话不可恢复。
