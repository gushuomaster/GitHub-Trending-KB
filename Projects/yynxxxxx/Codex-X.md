# yynxxxxx/Codex-X
## 项目定位
OpenAI Codex 桌面端/CLI 的跨平台可视化管理工具。
## 核心功能与技术特点
Rust；Provider/API 切换、会话同步、提示词注入、Skills/MCP 管理和 TOML 配置可视化。
## 适用场景
多 Provider Codex 使用、桌面化配置管理、Skills/MCP 调试。
## 主要优点
把分散的 Codex 配置面集中到 GUI；对多 Provider 与插件化工作流实用。
## 局限 / 注意点
第三方管理层需要持续追随 Codex CLI 配置和协议变化；API Key/凭据管理必须谨慎。
## 为什么值得记录
直接反映 Coding Agent 周边工具正在形成独立桌面管理层。

## 怎么利用
通过 GUI管理 Codex Provider、模型、会话、Skills/MCP 与 TOML 配置；切换 Provider 前备份配置并确认密钥不会泄露。

## 实际例子
**可推导用法：** 场景 → 在官方账号与自定义 API 间切换。输入 → 两组 Provider 配置。操作 → 在 Codex-X 选择配置并验证模型/Skills。输出 → 可视化切换后的 Codex 会话环境。
