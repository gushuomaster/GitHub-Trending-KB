# docling-project/docling

## 一句话说明
把 PDF、Office、HTML、图片等文档解析成保留结构的统一表示，供 GenAI、RAG、搜索和数据抽取管线使用。

## 它能做什么
- 解析 PDF、DOCX、PPTX、XLSX、HTML、图片等多种格式
- 恢复版面、阅读顺序、表格、公式、代码与图片信息
- 输出 DoclingDocument、Markdown、HTML 或 JSON
- 本地运行并集成 LangChain、LlamaIndex 等生态

## 怎么利用
官方 CLI：安装 `docling` 后运行 `docling document.pdf`；解析器识别章节、表格和图片并输出结构化结果，随后可按标题和页码切块，建立带来源定位的 RAG 索引。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方 CLI：安装 `docling` 后运行 `docling document.pdf`；解析器识别章节、表格和图片并输出结构化结果，随后可按标题和页码切块，建立带来源定位的 RAG 索引。

## 适合谁
构建企业 RAG、文档检索、表格抽取与知识库管线的数据和 AI 工程师。

## 局限 / 注意点
- 复杂版式、扫描件和 OCR 结果仍需抽样验收；处理不可信文档时要使用最新版本与隔离环境，防范压缩包、XML、HTML 和本地文件访问风险。
