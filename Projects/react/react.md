# react/react

## 一句话说明
React 是用于构建 Web 与原生用户界面的组件库，通过声明式组件和状态更新组织交互界面。

## 它能做什么
- 把界面拆成可组合组件，并根据 props 与 state 声明渲染结果。
- 使用 Hooks 在函数组件中管理状态、副作用和可复用逻辑。
- 同一组件模型可用于浏览器界面，并通过 React Native 构建原生应用。

## 怎么利用
如果要做一个可交互计数器，可在 React 项目中定义组件与 state，让按钮事件更新状态；React 只重渲染受影响界面，最终得到可复用的交互组件。

## 适合谁
构建交互式 Web 前端、跨平台界面或组件库的 JavaScript/TypeScript 开发者。

## 局限 / 注意点
React 只解决视图层和组件模型，不自带完整路由、数据持久化或后端；实际项目需选择框架或配套库，并正确处理状态与副作用。
