# tonhowtf/omniget

## 一句话说明
跨平台桌面媒体下载器，把课程、视频、音乐和电子书下载、队列管理与本地播放整合在一个界面中。

## 它能做什么
- 基于 yt-dlp 覆盖大量公开视频站点和多种媒体类型
- 支持 Udemy、Hotmart、Telegram 等专用下载流程与课程播放器
- 提供暂停、恢复、重试、并发队列和媒体转换
- 用 Tauri 桌面应用和 CLI 在 Windows、macOS、Linux 运行

## 怎么利用
公开镜像与项目索引中的流程：安装桌面版后粘贴有权下载的媒体或课程链接，选择格式与目录加入队列；应用调用站点适配器或 yt-dlp 下载，并在本地媒体库播放。
