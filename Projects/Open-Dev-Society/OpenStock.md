# Open-Dev-Society/OpenStock

## 一句话说明
开源股票市场看板，用搜索、关注列表、行情图表、公司信息和提醒替代部分付费市场终端体验。

## 它能做什么
- 通过 Finnhub 搜索股票并展示公司资料与新闻
- 用 TradingView 组件显示图表、热力图和技术指标
- 为用户保存 watchlist、风险偏好与关注行业
- 用 Inngest、邮件与可选 Gemini 生成欢迎和周报流程

## 怎么利用
官方 Quick Start：配置 MongoDB 与 Finnhub API Key，运行 `pnpm dev`，登录后把股票加入 watchlist 并查看 TradingView 图表；输出自托管的市场观察面板，邮件功能可按需另行配置。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方 Quick Start：配置 MongoDB 与 Finnhub API Key，运行 `pnpm dev`，登录后把股票加入 watchlist 并查看 TradingView 图表；输出自托管的市场观察面板，邮件功能可按需另行配置。

## 适合谁
需要自托管股票观察面板的个人研究者，以及学习 Next.js 金融应用集成的开发者。
