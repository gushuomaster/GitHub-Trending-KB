# heygen-com/hyperframes

## 一句话说明
用 HTML、CSS 和可定位动画描述视频画面，并把同一 composition 确定性渲染为 MP4，适合 Agent 自动制作视频。

**当前官方描述：** Write HTML. Render video. Built for agents.

## 它能做什么
- 用普通 HTML composition 和时间属性描述场景与轨道。
- 兼容 CSS、GSAP、Lottie、Three.js 等可逐帧定位的动画。
- 提供产品发布、PR 讲解、无真人解说、字幕等 Agent 工作流。

## 怎么利用
安装核心 Skills，输入脚本、品牌素材和目标时长；Agent 创建 composition，先预览和检查，再渲染为 MP4，可放入 CI 批量生成。

## 实际例子
**官方工作流 →** 输入一个 GitHub PR URL，调用 `/pr-to-video` 读取变更，生成带代码差异、旁白和字幕的功能讲解视频。

## 关键命令
```text
npx skills add heygen-com/hyperframes
```

## 适合谁
需要程序化制作产品发布片、代码演示、数据动画或社交短片的开发者和内容团队。

## 局限 / 注意点
更适合可编程排版与动画，不等同于写实视频生成模型；字体、媒体编解码器和动画库会影响渲染一致性。
