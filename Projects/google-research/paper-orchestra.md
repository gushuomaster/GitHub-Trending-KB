# google-research/paper-orchestra

## 一句话说明
PaperOrchestra 是自动撰写 AI 研究论文的多 Agent 框架，把研究想法、实验日志和 LaTeX 模板整理成可继续修改的论文工程。

## 它能做什么
- 编排提纲、文献综述、分节写作、内容反思和绘图等专门 Agent。
- 自动搜索、筛选并综合相关文献，将引用与论述整合进稿件。
- 生成图表或概念图，并按目标会议模板输出 LaTeX。

## 怎么利用
官方 CLI：准备包含想法和实验日志的原始材料目录及会议 LaTeX 模板，运行 `paper_writing_cli.py`；流水线在输出目录生成章节、图表和可编译稿件。

## 实际例子
**官方资料中的工作流 →** 官方 CLI：准备包含想法和实验日志的原始材料目录及会议 LaTeX 模板，运行 `paper_writing_cli.py`；流水线在输出目录生成章节、图表和可编译稿件。

## 关键命令
```bash
conda create -n paper_orchestra python=3.11
pip install -r requirements.txt
./paper_writing_cli.sh
```

## 适合谁
已有研究想法与实验记录、希望加速论文整理但会人工核验内容的 AI 研究者。

## 局限 / 注意点
仓库所用数据集尚未随代码发布；运行需要 Python 3.11、模型与文献服务密钥。自动生成的引用、论断、图表和投稿合规性必须由研究者逐项核验。
