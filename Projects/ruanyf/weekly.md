# ruanyf/weekly

## 一句话说明
长期维护的中文科技爱好者周刊仓库，每周策展文章、软件、开源项目、行业观察与招聘信息。

## 它能做什么
- 按周归档完整周刊正文并提供历史目录
- 持续汇总值得关注的工具、文章与开源项目
- 通过 GitHub Issue 接收社区投稿
- 在讨论区维护程序员招聘与求职信息

## 怎么利用
官方使用方式：每周五打开最新一期 `docs/issue-*.md`，按兴趣主题跟进原始链接；若发现合适的文章、软件或资源，可按仓库说明提交 Issue 供编辑筛选。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方使用方式：每周五打开最新一期 `docs/issue-*.md`，按兴趣主题跟进原始链接；若发现合适的文章、软件或资源，可按仓库说明提交 Issue 供编辑筛选。

## 适合谁
希望每周获取中文科技线索、开源项目与招聘信息的开发者和技术从业者。

## 局限 / 注意点
- 这是人工策展内容而非可执行软件；收录标准与观点具有主观性，外链会失效或内容变化，引用前必须回到原始来源复核。
