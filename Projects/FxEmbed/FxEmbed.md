# FxEmbed/FxEmbed

## 一句话说明
通过改写 X/Twitter 或 Bluesky 链接，让 Discord、Telegram 等聊天应用正确展示视频、多图、投票与翻译。

> 使用方式依据仓库当前 README 核对于 2026-09-28；这不代表历史上榜当日的 README 版本。

## 它能做什么
- 支持 X/Twitter、Bluesky 链接增强嵌入
- 可展示多图、视频、引用、投票与翻译
- 支持 Cloudflare Worker 部署，也提供 Docker 自托管路径

## 怎么利用
在聊天消息里把 `twitter.com` 改成 `fxtwitter.com`、把 `x.com` 改成 `fixupx.com`；团队需要自定义域名或品牌时可复制配置并用 Docker/Workers 部署。

## 实际例子
**官方示例：** 场景 → 在 Discord 分享一条含视频的 X 帖子。输入 → 原始 `x.com/user/status/...` 链接。操作 → 把域名改为 `fixupx.com` 后发送。输出 → Discord 直接显示可播放视频和完整媒体卡片。

## 适合谁
需要在聊天群稳定分享社交媒体内容的社区运营者，以及希望自托管嵌入代理的团队。

## 局限 / 注意点
依赖上游平台页面/API变化；自托管需配置域名、Worker 路由与缓存，并注意平台条款和隐私。
