# rohitg00/ai-engineering-from-scratch
## 一句话说明
一套从数学、ML、LLM 到 Agent、MCP 与生产系统的开源 AI 工程课程，强调每课都实际运行代码并留下可验证产物。
## 它能做什么
- 20 个阶段、523 节课程覆盖 AI 工程全链路。
- 提供 LLM Engineering、Agent Engineering、MCP、Agent Skills 等专项路径。
- 每课包含可运行代码，并产出 prompt、skill、agent 或 MCP server。
## 怎么利用
按目标选择学习路径；例如已有 Python 基础可直接进入 LLM Engineering 或 Agent Engineering，并运行每课代码、测试和产物。
## 实际例子
**场景 →** 系统学习 Agent Skills。 **输入 →** 本地 Codex/Claude Code。 **操作 →** `npx skills add rohitg00/ai-engineering-from-scratch`，再启动 `learn-agent-skills`。 **结果 →** 生成持续学习记录并按五课路线完成 contract、discovery、sandbox 与 release evals。
## 适合谁
AI 应用工程师、希望补齐底层原理与工程实践的开发者。
## 局限 / 注意点
课程规模很大；部分真实实验需要 Python/Node 和支持 Skills 的 Agent host。
