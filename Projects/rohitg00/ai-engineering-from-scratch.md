# rohitg00/ai-engineering-from-scratch

## 一句话说明
一套从数学、机器学习到 LLM、Agent、MCP 和生产系统的开源课程，每课要求运行代码并留下可验证产物。

## 它能做什么
- 20 个阶段、523 节课程覆盖 AI 工程全链路。
- 提供 LLM Engineering、Agent Engineering、MCP 与 Agent Skills 专项路径。
- 每课包含可运行代码，并产出 prompt、skill、agent 或 MCP server。
- 提供 placement tutor 和多语言学习入口。

## 怎么利用
先按目标选择学习路径，再逐课阅读原理、手写关键代码、运行命令并保存输出证据；已有 Python 基础可直接进入 LLM 或 Agent 路线。

## 实际例子
**场景 →** 系统学习 Agent Skills。 **输入 →** 本地 Codex/Claude Code 和课程 Skill。 **操作 →** 执行 `npx skills add rohitg00/ai-engineering-from-scratch`，再启动 `learn-agent-skills`。 **输出 →** 按五课路线完成 contract、discovery、sandbox 与 release evals，并留下学习记录。

```bash
git clone https://github.com/rohitg00/ai-engineering-from-scratch.git
cd ai-engineering-from-scratch
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

## 适合谁
希望补齐底层原理、代码实现与生产工程的 AI 应用开发者。

## 局限 / 注意点
课程体量约 342 小时，不能把浏览内容当成完成；不同实验需要 Python、Node 或特定 Agent host，跳过先修知识会明显增加理解成本。
