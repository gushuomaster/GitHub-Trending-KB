# Homebrew/BrewUI

## 一句话说明
Homebrew 的原生 macOS 图形界面，让公式与 Cask 的发现、安装、更新和移除过程可见、可控。

## 它能做什么
- 浏览、搜索并安装 Homebrew formulae 与 casks
- 集中查看可更新包并执行升级或卸载
- 显示底层 brew 操作、状态和错误，便于排查
- 结合本机 brew CLI 与 Homebrew JSON API 提供 SwiftUI 原生体验

## 怎么利用
官方安装流程：先确保 Homebrew 可用，再执行 `brew install --cask homebrew-app`；打开 BrewUI，选择软件包并审阅实际 brew 操作与结果。


## 适合谁
希望用原生界面管理 Homebrew 软件包，同时仍能看到实际命令与状态的 macOS 用户。

## 局限 / 注意点
- 仅适用于 macOS 且依赖有效的 Homebrew 安装；应用使用自己的 `brew.env`，与交互式 shell 环境不完全相同，复杂配方问题仍需回到 CLI 排查。
