# bregman-arie/devops-exercises

## 一句话说明
用按主题组织的问答与练习检查 DevOps、SRE、云平台、容器、网络、Linux 和数据库等基础知识，适合自学查漏与面试前演练。

## 它能做什么
- 收录 2600 余道问题与练习，覆盖 Linux、Git、网络、Kubernetes、CI/CD、AWS、Azure、GCP、Terraform、数据库与可观测性等主题。
- 各主题既有概念问答，也包含命令、故障分析和实践题，可按技术栈选择性学习。
- 折叠答案便于先独立作答，再与仓库解释对照。
- 提供贡献指南，允许补充新题、改进答案或整理专题资料。

## 怎么利用
先按当前岗位或薄弱环节选择专题，逐题口述或写下答案，再展开仓库答案核对；把错误题和无法解释的命令整理成复习清单，最后选择相关实践题在测试环境完成并记录结果。

## 实际例子
**官方内容 → 场景：** 复习网络基础。**输入：** Network 章节中关于 TCP/IP、MAC 地址、广播地址与 IP 地址的问题。**操作：** 先自行解释通信所需条件和协议作用，再展开每题答案比较遗漏。**输出：** 一份明确列出概念误区的复习清单，可继续延伸到 DNS、容器网络或云网络专题。

## 适合谁
准备 DevOps/SRE 面试、设计团队培训题库，或希望系统补齐基础设施知识的工程师与学习者。

## 局限 / 注意点
- README 明确说明多数题目不代表真实面试流程，不能把背题等同于岗位能力。
- 主题覆盖很广，不要求也不建议一次学完全部技术；应结合实际工作选择范围。
- 部分题目和答案由社区维护，生产决策前仍需对照官方文档与当前版本验证。
