# chrislgarry/Apollo-11

## 一句话说明
保存并校对阿波罗 11 号指令舱与登月舱制导计算机的原始汇编源代码，让历史软件可检索、研究和复现。

**官方描述：** Original Apollo 11 Guidance Computer (AGC) source code for the command and lunar modules.

## 它能做什么
- 收录指令舱 Comanche055 与登月舱 Luminary099 的 AGC 源代码。
- 将 MIT Museum 的纸质扫描件转录成可浏览、搜索和比较的文本。
- 接受对照原始扫描发现的转录错误、缺字和遗漏文件修正。
- 提供多语言 README，并链接 Virtual AGC 工具链进行组装与仿真。

## 怎么利用
把仓库当作可检索的历史源码档案：从 Comanche055 或 Luminary099 中选择程序模块，对照仓库链接的原始扫描研究导航、任务调度或控制逻辑；需要执行时转到 README 指向的 Virtual AGC 工具链组装和仿真。

## 实际例子
**官方贡献场景 → 场景：** 校对登月舱程序转录。**输入：** Luminary 099 原始扫描页与对应 .agc 文件。**操作：** 逐行比较标签、操作码和注释，按 CONTRIBUTING 提交确有证据的修正。**输出：** 更接近 MIT Museum 原件、可被搜索和组装工具使用的文本源码。

## 适合谁
研究计算机史、航天软件、早期实时系统或汇编语言的学生、研究者，以及参与史料数字化校对的贡献者。

## 局限 / 注意点
这是历史源码档案，不是现代航天飞控 SDK；组装与仿真依赖外部 Virtual AGC。转录文件可能仍与扫描原件存在差异，仓库也不等同于完整的 Apollo 任务软件与硬件环境。
