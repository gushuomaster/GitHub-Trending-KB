# TauricResearch/TradingAgents

## 一句话说明
用基本面、技术、新闻、情绪、交易员和风险经理等多 Agent 模拟交易公司研究与决策流程。

## 它能做什么
- 并行运行基本面、情绪、新闻和技术分析角色
- 通过多空研究员辩论与管理者汇总形成观点
- 由交易员、风险团队和投资组合经理给出决策
- 支持多模型供应商、检查点恢复、历史回测和报告

## 怎么利用
官方 CLI 场景：指定 ticker 与分析日期，系统并行收集当时可得的基本面、新闻和市场数据，各角色讨论后输出带设置记录的交易报告与决策。

## 适合谁
研究多 Agent 金融分析、回测和决策流程的量化研究者。

## 局限 / 注意点
- 框架输出不构成投资建议，LLM 会幻觉且市场数据可能延迟；即使修复了前视偏差，回测也不能保证实盘表现，任何交易都需独立风控。
