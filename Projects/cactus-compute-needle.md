# cactus-compute/needle
## 项目定位
面向手机、穿戴、机器人、汽车和微控制器的超小型 Automation Foundation Model。
## 核心功能 / 实现特点
2-bit、8–29MB 级模型，面向 tool calling、结构化抽取与 embeddings；Python/JAX + Cactus 原生推理栈；仓库 9/19 仍有更新。
## 最近变化
