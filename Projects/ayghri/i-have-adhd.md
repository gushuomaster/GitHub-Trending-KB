# ayghri/i-have-adhd

## 一句话说明
A skill to stop your coding agent from burying the answer. ADHD-friendly output.

## 它能做什么
- 给 Coding Agent 加一组输出行为规则，让回答先给动作、步骤编号、减少旁支和冗余。
- 可作为实际工作流中的独立工具或 Agent 能力使用。

## 怎么利用
给 Coding Agent 加一组输出行为规则，让回答先给动作、步骤编号、减少旁支和冗余。

## 实际例子
场景：Agent 经常输出很长但下一步不明确 → 安装该 skill/plugin → 同一个修复任务会优先给出要改的文件、编号步骤和测试命令 → 输出更短、更可执行的回复。

## 适合谁
需要解决上述问题的开发者、工程团队或自托管用户。

## 局限 / 注意点
它主要改变交互/输出风格，不提高底层模型事实正确率；规则可能不适合需要长篇论证的任务。
