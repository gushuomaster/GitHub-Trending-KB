# ayghri/i-have-adhd

> 功能和用法按 2026-10-13 当前官方资料核对，不声称等同于历史上榜日版本。历史统计未保存时保持空值，不使用当前值补写。

## 一句话说明
给 Coding Agent 加一套“行动在前、步骤编号、减少旁支”的输出规则，让修复建议更短、更容易执行。

## 它能做什么
- 把下一步行动放在回复开头，并为多步骤任务编号。
- 限制旁支话题和列表长度，减少无关铺垫。
- 每轮重述当前状态，并用一个具体下一步收尾。

## 怎么利用
安装技能后，把明确的代码问题交给 Agent；技能约束回复结构，输出要修改的文件、操作步骤和验证命令。

## 实际例子
**官方 Before/After →** 输入 `src/auth.ts` 的 token 验证问题；启用技能后，回复先指出文件和函数，再列替换代码、运行 `npm test -- auth.spec.ts` 以及失败时应提供的首条报错。

## 适合谁
需要快速从 Agent 回复中识别下一步动作的开发者，尤其适合容易被长篇铺垫分散注意力的用户。

## 局限 / 注意点
主要改变回复组织方式，不会提升底层模型的事实正确率；需要长篇论证时，强制短回复可能丢失必要背景。
