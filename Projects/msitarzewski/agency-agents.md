# msitarzewski/agency-agents

> 功能和用法按 2026-10-13 当前官方资料核对，不声称等同于历史上榜日版本。历史统计未保存时保持空值，不使用当前值补写。

## 一句话说明
按前端、设计、营销、安全等专业角色组织的 Agent 指令库，可选择角色安装进多种 Coding Agent。

## 它能做什么
- 角色文件包含身份、任务、工作流、交付物和成功指标。
- 用转换与安装脚本为不同宿主生成集成文件，按 division 或 agent 选择安装。
- 可用配套桌面应用浏览角色库，也可直接阅读和改写 Markdown。

## 怎么利用
先查看角色列表，按当前任务选择少量角色；例如在仓库运行 `./scripts/install.sh --tool codex`，或用 `--division engineering,security` 限定团队。把明确任务交给已安装角色并检查输出。

## 实际例子
**可推导用法 → 场景：** 为 React 页面同时进行实现和设计检查。**输入：** 页面需求与现有组件。**操作：** 选择 Frontend Developer 与 UI Designer 角色，分别生成实现建议和视觉检查。**输出：** 代码/设计反馈，由真实宿主负责执行与上下文传递。

## 适合谁
希望借用专业角色指令，但保留现有 Agent 宿主与工具的个人和团队。

## 局限 / 注意点
主要是角色和工作流定义，不能保证自动形成可协作的完整团队；批量安装会增加选择成本和角色冲突，模型、工具权限与执行能力由宿主提供。
