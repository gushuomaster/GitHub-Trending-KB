# tradesdontlie/tradingview-mcp
## 项目定位
把 Claude Code 与 TradingView Desktop 连接起来的交易图表分析 MCP/自动化桥。
## 核心功能 / 实现特点
JavaScript；复用 TradingView Desktop 的现有图表环境，让 Agent 参与个人分析工作流，而不是重建行情终端。
## 主要优点
量化/交易垂直 MCP 具有参考价值，体现 Agent 与专业桌面软件组合的路线。
## 局限 / 注意点
图表分析不等于可盈利 Alpha；自动执行必须独立验证数据、滑点、风控和账户权限，不能把 LLM 输出直接视为交易建议。
