# ever-co/ever-gauzy

## 一句话说明
把 ERP、CRM、HRM、招聘、项目和工时管理整合到同一个开源业务管理平台中。

## 它能做什么
- 管理员工、候选人、客户、供应商与多个组织
- 记录工时、活动、绩效、休假与审批
- 管理项目、任务、销售管道、发票、费用与库存
- 通过 Headless API、桌面计时器和多语言界面扩展

## 怎么利用
官方工作流：在自托管实例中创建组织与员工，配置项目和费率；员工通过桌面计时器记录任务，经理在 Dashboard 审核工时、费用和绩效，再生成发票或报告。

## 实际例子

## 适合谁
需要自托管 ERP/CRM/HR、工时与项目数据的机构、代理公司和分布式团队。

## 局限 / 注意点
- 功能面广导致部署、升级和权限配置复杂；AGPL 许可、员工活动监控的隐私合规，以及 README 标注仍在 alpha 的 SaaS 环境都需要评估。
