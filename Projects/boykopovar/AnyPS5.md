# boykopovar/AnyPS5

## 一句话说明
Tool for automatic PS5 executables porting to Linux and Windows

## 它能做什么
- 把合法取得的 PS5 可执行程序重链接为 Windows/Linux 原生格式，并提供系统库兼容层和 shader 重编译。
- 可作为实际工作流中的独立工具或 Agent 能力使用。

## 怎么利用
把合法取得的 PS5 可执行程序重链接为 Windows/Linux 原生格式，并提供系统库兼容层和 shader 重编译。

## 实际例子
场景：兼容性研究 → 输入自己合法取得的 PS5 可执行文件 → 按官方 Usage 配置 AnyPS5 → relinker 转换目标格式并用兼容库运行 → 输出可在 PC 上启动的兼容版本；官方列出 Dreaming Sarah 已验证运行。

## 适合谁
需要解决上述问题的开发者、工程团队或自托管用户。

## 局限 / 注意点
项目仍在兼容性建设中，并非所有游戏/系统调用都支持；不提供固件、密钥或版权软件。
