# solidjs/solid

## 一句话说明
Solid 是细粒度响应式 JavaScript UI 库，组件只执行一次，后续由 signals、memos 和 stores 精确更新真实 DOM。

## 它能做什么
- 用细粒度依赖追踪减少无关重渲染。
- 提供 signals、memos、stores 与异步资源。
- 支持 SSR、流式渲染和渐进式 hydration。

## 怎么利用
场景：构建实时筛选列表。用 signal 保存筛选词、memo 计算结果，输入变化时只更新相关 DOM；输出保持响应的列表界面。

**场景 →** 场景：构建实时筛选列表。用 signal 保存筛选词、memo 计算结果，输入变化时只更新相关 DOM；输出保持响应的列表界面。

## 关键命令
```bash
npm init solid
```

## 适合谁
重视细粒度响应式性能、正在构建现代 Web UI 的前端工程师。

## 局限 / 注意点
Solid 2.0 与 1.x 存在迁移差异；生态和组件兼容性需核对，官方支持现代浏览器与 Node LTS 范围。
