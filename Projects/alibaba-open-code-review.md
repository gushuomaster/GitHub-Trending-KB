# alibaba/open-code-review

## 项目定位
确定性工程管线 + LLM 的 AI Code Review CLI，面向本地、CI 与 Agent 工作流。

## 核心功能 / 实现特点
Go 核心；diff selection、coverage、分组、token budget、line-level comment、session compare、VS Code/Agent/Skills 集成。

## 主要优点
- 不只是“把 diff 丢给 LLM”，确定性 selection 与 comment 定位降低噪声。
- 大 changeset token、preview parity、路径安全等工程边界处理扎实。

## 局限 / 注意点
- AI finding 仍可能误报/漏报，不能替代静态分析、测试与人工安全审查。
- 大仓库仍需调模型窗口、预算与 Provider 成本。
