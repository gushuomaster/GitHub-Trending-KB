# anthropics/knowledge-work-plugins
## 项目定位
Anthropic 面向知识工作者的开源插件集合，把专业工作流程封装成可复用 Agent 能力。
## 核心功能 / 实现特点
Python 主体、Apache-2.0；插件化组织专业领域工作流，并通过自动化持续更新外部插件版本。
