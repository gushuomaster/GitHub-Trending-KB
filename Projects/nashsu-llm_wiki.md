# nashsu/llm_wiki

## 项目定位
把文档增量转化为持久、互链 Wiki/知识图谱，强调长期知识维护而非每次查询时临时 RAG。

## 核心功能 / 实现特点
- TypeScript 桌面应用。
- 两阶段 ingest、来源追溯、多模态、知识图谱、Louvain 社区、可选 LanceDB、文件夹监听、Deep Research、本地 API/Agent Skill。
- 图关系融合 direct links、source overlap、Adamic-Adar、type affinity。

## 主要优点
- 更接近长期知识资产，而非一次性问答。
- 适合 Agent Memory 和项目知识库。
- 图结构、增量更新和来源追溯设计完整。

## 局限 / 注意点
- 自动知识图谱质量依赖抽取模型。
- 合并、去重、更新策略比传统 RAG 更复杂。
- 当前代码 push 与 Trending 热度存在背离，维护节奏需要观察。
