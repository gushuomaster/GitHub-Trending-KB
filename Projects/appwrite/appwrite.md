# appwrite/appwrite

## 一句话说明
Appwrite 是开源应用后端平台，为 Web、移动端和 Agent 提供认证、数据库、存储、函数、站点与实时能力。

## 它能做什么
- 统一提供 Auth、Database、Storage 与 Functions。
- 支持 Sites、Messaging、Realtime 和网络防护。
- 通过 SDK、API 与 MCP 接入开发或 Agent 工作流。

## 怎么利用
场景：自托管一个应用后端。用官方 Docker 安装器启动服务，在控制台创建项目、数据库和认证；客户端通过 SDK 写入数据并订阅实时更新。

## 关键命令
```bash
docker run -it --rm \
  --volume /var/run/docker.sock:/var/run/docker.sock \
  appwrite/appwrite:latest install
```

## 适合谁
需要统一应用后端、希望使用托管服务或自托管平台的全栈与移动开发团队。

## 局限 / 注意点
自托管安装涉及 Docker 套接字和多项基础设施；生产环境需负责备份、升级、密钥、网络和资源容量，MCP 权限也应最小化。
