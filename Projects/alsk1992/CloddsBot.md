# alsk1992/CloddsBot

## 一句话说明
覆盖预测市场、加密现货/期货和 DeFi 的自托管 AI 交易 Agent，把扫描、下单和风控接成一条流程。

## 它能做什么
- 连接 Polymarket、Kalshi、Binance、Hyperliquid 和多条 EVM/Solana 市场
- 扫描价差或事件机会，并通过交易终端执行订单
- 提供 Risk Engine、仓位管理和多渠道通知
- 用 SQLite 保存会话与历史，并提供 WebChat 和 CLI

## 怎么利用
官方演示：安装后运行 `clodds onboard`，向导配置凭据并拉取 Polymarket 的 15 分钟 BTC 预测市场；确认风险参数后才能进入实际交易。

## 实际例子
**官方材料中的工作流：** 官方演示：安装后运行 `clodds onboard`，向导配置凭据并拉取 Polymarket 的 15 分钟 BTC 预测市场；确认风险参数后才能进入实际交易。

## 关键命令
```bash
npm install -g https://github.com/alsk1992/CloddsBot/releases/latest/download/clodds.tgz --loglevel=error
clodds onboard
```

## 适合谁
研究预测市场和加密交易自动化、且能承担密钥与资金安全责任的量化开发者。

## 局限 / 注意点
- 需要保管交易 API key、钱包和真实资金，错误配置可能造成损失；Agent 的机会判断不保证盈利，低流动性、滑点和合约规则必须单独核对。
