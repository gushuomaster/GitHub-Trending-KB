# asciimoo/hister

## 一句话说明
本地优先的全文检索工具，把访问过的网页、书签和本地文件建立索引，并通过 Web、TUI、CLI 或 MCP 找回。

## 它能做什么
- 由浏览器扩展索引访问历史与网页内容
- 导入书签、历史记录和指定目录文件
- 提供 Web、TUI、CLI 与 MCP 搜索入口
- 可选语义搜索并支持多用户部署

## 怎么利用
官方 Quick Start：安装二进制后运行 `hister listen`，在本机 4433 端口启动服务并安装浏览器扩展；之后用 Web 或终端输入关键词，得到过去看过的页面和本地文件结果。

## 实际例子
**场景 → 输入 → 操作 → 输出：** 官方 Quick Start：安装二进制后运行 `hister listen`，在本机 4433 端口启动服务并安装浏览器扩展；之后用 Web 或终端输入关键词，得到过去看过的页面和本地文件结果。

## 关键命令
```bash
hister listen
```

## 适合谁
经常需要找回过去浏览页面或本地资料、同时希望数据留在自有环境的研究者与知识工作者。

## 局限 / 注意点
- 索引可能包含浏览历史、页面正文和本地敏感文件；需保护服务端口、存储与备份，并审查扩展权限，多用户部署还要落实账户隔离。
