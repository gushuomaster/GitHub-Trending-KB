# liquidslr/system-design-notes

## 一句话说明
把《System Design Interview》两卷的主题整理成按案例浏览的学习笔记，帮助读者练习分布式系统设计面试。

**官方描述：** Notes of the book System Desgin Interview - An Insider's Guide

## 它能做什么
- 按章节整理容量估算、系统设计框架、限流、一致性哈希等基础方法。
- 覆盖 URL Shortener、聊天、消息队列、支付、对象存储等 28 个设计案例。
- 为限流、Dynamo、Snowflake、爬虫和视频系统等主题汇总延伸资料。

## 怎么利用
输入要练习的系统题目和容量假设，先阅读估算与通用框架，再进入对应案例核对组件、数据流和权衡；输出一份包含需求、规模估算、接口、数据模型、关键组件和瓶颈的面试设计提纲。

## 实际例子
**可推导用法 → 场景：** 练习设计 URL 短链服务。**输入：** 读写比例、预计链接量和延迟目标。**操作：** 先用容量估算章节计算存储与吞吐，再阅读 URL Shortener、唯一 ID 和缓存相关笔记，画出请求路径并说明冲突处理。**输出：** 可用于模拟面试的系统方案与待验证权衡。

## 适合谁
准备系统设计面试、复习分布式系统案例或需要快速建立设计题框架的软件工程师。

## 局限 / 注意点
README 明确说明笔记仍在完善；它是对书籍的学习整理，不是可运行的软件，也不能替代原书和最新生产系统文档。仓库没有声明主要编程语言或许可证。
