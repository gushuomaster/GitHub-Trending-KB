# jamiepine/voicebox

## 一句话说明
本地优先的 AI 语音工作室，在一套桌面应用中完成声音克隆、语音生成、听写、转录和 Agent 语音输出。

## 它能做什么
- 用八种 TTS 引擎克隆或设计声音，覆盖多语言和表达控制
- 通过全局热键听写到任意文本框，并用 Whisper 做语音转文字
- 用故事编辑器、异步队列、版本和后处理制作长音频
- 通过本地 REST API 与 MCP 让脚本和 Agent 调用发声、转录与语音档案

## 怎么利用
官方流程：安装桌面版，导入一段有授权的参考录音创建 voice profile，再输入文本生成语音；也可把本地 MCP 地址加入 Claude Code 等客户端，让 Agent 调用 `voicebox_speak` 输出指定声音。

## 适合谁
需要本地完成配音、听写、转录或为 Agent 增加语音输出的创作者与开发者。

## 局限 / 注意点
- 模型下载、GPU/CPU 性能和磁盘占用会影响体验，Linux 预编译包尚不可用；声音克隆必须得到授权，本地 API 与 MCP 也应限制可访问客户端。
