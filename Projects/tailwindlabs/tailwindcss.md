# tailwindlabs/tailwindcss

## 一句话说明
Tailwind CSS 是 utility-first CSS 框架，让开发者直接组合原子化类名构建自定义界面，而不必为每个组件编写独立样式表。

## 它能做什么
- 用间距、颜色、布局、响应式和状态类快速组合界面。
- 按项目实际使用的类生成 CSS，减少未使用样式。
- 支持主题变量、暗色模式、响应式断点和常见构建工具集成。

## 怎么利用
在前端项目安装 Tailwind 并接入构建流程，在 HTML/JSX 上组合 `flex`、`p-*`、`text-*` 等 utility 类；构建后输出只包含项目需要的 CSS。

## 关键命令
```bash
npm install tailwindcss
```

## 适合谁
需要快速构建定制 Web 界面并统一样式约束的前端开发者和设计系统团队。

## 局限 / 注意点
它不是现成组件库，也不决定交互和可访问性；大量类名会进入模板，动态拼接类名可能无法被构建扫描识别，升级时需核对构建插件和配置变化。
