# Tencent/BrowserSkill

## 一句话说明
把 AI Agent 连接到用户已登录的 Chrome 或 Edge，让它在可见的独立窗口中读取、交互和调试网页。

## 它能做什么
- 复用现有浏览器账号状态，读取文档、填写表单并完成网站流程
- 在独立 Agent Window 运行，必要时借用并归还现有标签页
- 检查页面、网络请求、响应、控制台与性能证据，支持请求重放
- 管理标签页、截图和本地文件上传下载，并导出操作证据

## 怎么利用
官方 Quick Start：安装 `bsk` CLI 和 Chrome/Edge 扩展，为 Coding Agent 安装 BrowserSkill 后运行连接检查；给出“打开指定站点并保存完整截图”等任务，Agent 在可见窗口执行，登录或验证码交还人工。

## 实际例子
**资料中的具体工作流：** 官方 Quick Start：安装 `bsk` CLI 和 Chrome/Edge 扩展，为 Coding Agent 安装 BrowserSkill 后运行连接检查；给出“打开指定站点并保存完整截图”等任务，Agent 在可见窗口执行，登录或验证码交还人工。

## 关键命令
```bash
bsk --version
```

## 适合谁
需要让 Coding Agent 使用真实账号态网页，又希望保留可见性、人工接管和调试证据的开发者。

## 局限 / 注意点
- 它能够访问登录态、Cookie、页面数据和下载文件，必须限制 Agent、浏览器档案与写操作权限；网站反自动化、DOM 变化和浏览器兼容性也会造成失败。
