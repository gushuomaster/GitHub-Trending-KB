# Orkas-AI/Orkas

## 一句话说明
把持续性目标拆成待办并交给桌面端多 Agent 团队执行，让研究、写作、开发、媒体与办公任务在同一项目上下文中持续推进。

## 它能做什么
- Commander 会分解目标、选择合适的内置专家或外部 CLI Agent，并汇总交付物。
- 项目保存目标、规则、记忆和文件，配合待办与 Auto-advance 自动衔接后续工作。
- 内置 16 个研究、内容、媒体、开发、办公与电商专家，并可接入 Claude Code、Codex、OpenCode、OpenClaw 和 Hermes-Agent。
- 支持按小时、天、周或月运行自动化，并连接 Gmail、日历、Drive、Slack、Shopify 等服务。

## 怎么利用
在 macOS 或 Windows 安装应用，新建项目并写入目标、规则与参考文件；把目标交给 Commander，它会生成待办、分派给专家或本机 CLI Agent，处理过程中保留项目记忆，最终把报告、代码、文档或媒体文件送回审阅。

## 实际例子
**官方示例 → 场景：** 为产品发布准备整套素材。**输入：** 产品资料、目标市场和参考风格。**操作：** Commander 先安排市场研究，再把结论交给 ContentWriter、PptMaker 与 VideoStudio。**输出：** 有来源的研究报告、可编辑演示文稿和发布视频；各交付物回到同一项目中供人工复核。

## 关键命令
~~~sh
git clone https://github.com/Orkas-AI/Orkas.git
cd Orkas
bun install
~~~

## 适合谁
需要让多个 Agent 持续协作并统一管理项目记忆、待办和交付物的独立开发者、内容团队与小型业务团队。

## 局限 / 注意点
- 开源源码版不包含共享项目、云同步和 Web App 发布；这些能力属于打包应用。
- 外部 CLI Agent 需要本机已安装并各自配置模型；使用自有模型密钥或第三方连接器时仍需评估成本、权限和数据去向。
- Auto-advance 和定时任务会持续执行工作，重要的发送、发布、删除或业务决策应保留人工确认。
