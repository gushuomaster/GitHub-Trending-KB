# mvt-project/mvt
## 项目定位
Mobile Verification Toolkit，用于移动设备取证并寻找潜在入侵或间谍软件迹象。
## 核心功能与技术特点
Python 工具链，围绕 iOS/Android 备份、日志、IOC 与取证分析构建。
## 适用场景
移动安全调查、数字取证、威胁研究。
## 主要优点
用途明确、专业安全价值高，覆盖主流移动平台取证流程。
## 局限 / 注意点
检测结果需要专业解释；取证链、隐私和证据保全要求高，未命中 IOC 不等于设备安全。
