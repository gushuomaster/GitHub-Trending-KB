# anthropics/financial-services
## 项目定位
Anthropic 面向金融服务场景公开的 AI 能力/工作流资源库。
## 核心功能与技术特点
以 Python 为主要语言，面向金融研究和专业知识工作；重点价值在领域工作流、工具使用和金融语境约束，而非单一交易策略。
## 适用场景
金融研究、分析自动化、专业知识工作与金融 Agent 参考实现。
## 主要优点
