# coreyhaines31/marketingskills

> 功能和用法按 2026-10-13 当前官方资料核对，不声称等同于历史上榜日版本。历史统计未保存时保持空值，不使用当前值补写。

## 一句话说明
为 AI Agent 提供一组可组合的营销技能，覆盖产品定位、转化率、文案、SEO、分析、获客和生命周期运营。

## 它能做什么
- 以 `product-marketing` 上下文作为其他营销技能的共同基础。
- 覆盖 CRO、文案、SEO 审计、分析、定价、邮件、社交和发布等任务。
- 可按单个技能安装，也可通过 Claude Code 或 Codex 插件引入。

## 怎么利用
先建立产品、受众和定位上下文，再只安装当前任务需要的技能；把网页、目标指标和约束交给 Agent，输出可审查的诊断与改写方案。

## 实际例子
**官方 Usage →** 输入“Help me optimize this landing page for conversions”；Agent 触发 `cro` 技能，结合产品上下文检查页面并提出转化改进。

## 适合谁
需要让 Agent 执行 SaaS 营销、SEO、文案和增长任务的创始人、增长团队及内容人员。

## 局限 / 注意点
技能提供框架和建议，不替代真实用户研究与实验数据；批量安装会增加触发冲突，旧版技能目录升级后可能残留重复名称。
