**定位**：Coding Agent 多阶段安全审计 Skill。

**优点/场景**：适合把 Agent 安全审计纳入 CI；“发现—验证”分离和覆盖账本是当前 Skills 工程化的重要参考。

**变化**：连续高热度但代码未继续加速，评分维持 9.7。

## 2. [[Tencent-WeKnora]] — 9.7/10
**定位**：RAG + 推理 Agent + 自维护 Wiki 的长期知识平台。  
**核心功能**：文档摄取、混合检索、自治推理、知识库/Wiki 与多租户服务。  
**优点/场景**：适合企业知识库和长期 Agent Context；相比单纯向量库，更强调知识生命周期。  
**技术特点**：Go 为主；近期持续处理知识状态一致性、任务恢复和服务治理。  
**热度/活跃度**：最近一轮仍处高位，约 **+858~1123 stars/day**。  
**局限**：部署、多租户、队列和知识一致性带来较高运维复杂度。  
**变化**：从“RAG 产品”持续向“Agent 长期知识系统”演进，评分维持 9.7。

## 3. [[Tencent-BrowserSkill]] — 9.6/10
**定位**：让 AI Agent 复用用户真实登录浏览器的 Browser Skill/CLI + Extension。  
**核心功能**：在不重新登录的情况下让 shell-capable Agent 操作真实浏览器，覆盖标签页、页面交互和自动化。  
**优点/场景**：适合需要真实登录态、Cookie、现有工作标签页的 Browser Agent；比独立 Playwright 容器更贴近用户真实环境。  
**技术特点**：TypeScript；浏览器扩展 + CLI 架构，近期重点围绕后台标签页截图和减少对用户前台操作的干扰。  
**热度/活跃度**：最近可验证日榜约 **+744 stars**，已进入 5k+ 区间。  
**局限**：真实登录态意味着权限风险更高；扩展、页面权限和敏感操作必须有审批边界。
