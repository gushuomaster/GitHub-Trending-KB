## 1. [[Tencent-WeKnora]] — 9.7/10
**定位**：RAG + 自治推理 Agent + 自维护 Wiki 的企业知识平台。  
**核心功能**：文档摄取、embedding/reranking、语义/向量检索、多租户、Agent 推理与 Wiki。  
**优点/场景**：适合企业知识库、长期 RAG 与 Agent Context；不是单纯向量数据库，而是知识生命周期平台。

**热度/活跃度**：**+1123 stars**，较昨日 +696 明显加速。  
**局限**：系统面较宽，部署、多租户、任务队列与知识状态一致性都增加运维复杂度。  
**变化**：评分 9.5→9.7，原因不是 Star 单独上涨，而是热度与真实工程修复同步。

## 2. [[alphaXiv-OpenResearch]] — 9.6/10
**定位**：把 Coding Agent 转成结构化 Research Agent 的 local-first 工作台。  
**核心功能**：研究项目、文献/假设、实验、结果综合与跨 Harness 会话。  
**优点/场景**：适合技术调研、论文复现、实验型研发；研究过程比普通一次性 Deep Research 更可持续。  
**技术特点**：Rust 主体，强调本地研究项目与 Agent 工具链整合。  
**热度/活跃度**：**+940 stars**，较昨日 +531 大幅回升。  
**局限**：研究自动化不等于结论可信，来源、实验复现和模型幻觉必须独立验证。  
**变化**：连续上榜且增速再次扩大，评分维持 9.6。

## 3. [[JustVugg-colibri]] — 9.5/10

**核心功能**：专家从磁盘流式加载，组合 NVMe/RAM/VRAM 运行超出显存容量的模型。  
**优点/场景**：适合研究低成本大 MoE 推理、异构内存和 SSD offload。  
**技术特点**：C；极简运行时，性能高度依赖磁盘带宽、专家命中与后端实现。  
**热度/活跃度**：**+872 stars**，较昨日 +2026 回落但仍在高位。  
**局限**：能运行不等于高吞吐；GPU/Vulkan、量化正确性和 prefix reuse 仍应实测。  
**变化**：热度降温但技术价值未变，评分维持 9.5。
