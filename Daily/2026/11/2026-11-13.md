## 3. [[Projects/nvm-sh/nvm|nvm-sh/nvm]]

**简介：** nvm 在同一用户和 Shell 中安装、切换并运行多个 Node.js 版本，避免不同项目互相覆盖运行环境。

**官方描述：** Node Version Manager - POSIX-compliant bash script to manage multiple active node.js versions.

**主要功能 / 特点：**
- 安装、列出、卸载和切换任意可用 Node.js 版本。
- 通过别名或 `.nvmrc` 固定项目版本，并在当前 Shell 调整 PATH。

**怎么利用 / 实例：** **官方命令工作流 →** 新服务需要 Node 24、旧脚本仍要求 Node 22 时，分别执行 `nvm install 24`、`nvm use 24`，并以 `nvm exec 22 node --version` 验证旧环境；输出彼此隔离的 Node/npm 运行环境。

**局限 / 注意点：** nvm 面向 POSIX 兼容 Shell，原生 Windows 不受支持，Windows 通常通过 WSL 使用；它按用户和 Shell 修改环境，新终端需加载初始化脚本，下载或编译版本也会消耗时间与磁盘。
