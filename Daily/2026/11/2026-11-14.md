**简介：** Tailcat 把 Tailscale 的开源数据平面做成类似 netcat 的点对点隧道工具，不依赖 Tailscale 账户或控制平面，也不修改系统路由和 DNS。

**官方描述：** like netcat, but over Tailscale's data plane, without Tailscale's control plane

**主要功能 / 特点：**
- 通过 WireGuard、magicsock 和 DERP 建立端到端加密隧道，并尽量升级为直连 UDP。

- 默认使用单次临时密钥，也支持保存密钥、客户端 allowlist、自建 DERP 和 Go 库集成。

**怎么利用 / 实例：** **官方最小场景 →** 服务端直接运行 `tailcat` 得到一次性 `tc...` 地址，客户端执行 `echo hello | tailcat <地址>`；输出通过加密隧道到达服务端标准输出。

**局限 / 注意点：** `tc...` 地址默认是包含预共享密钥的 bearer capability，泄露即可能授权连接；保存地址会跨重启持续有效。CLI、Go API 和线协议没有稳定承诺，公共 DERP 有限流且无可用性或吞吐 SLA。
