## 13. [[Projects/M-Abozaid/esp32-c3-adblock|M-Abozaid/esp32-c3-adblock]]

**简介**：在 ESP32-C3 上运行的 DNS 域名拦截器，把域名哈希存入 flash，降低对 RAM 和 PSRAM 的需求。

**主要功能 / 特点**：

- 将域名转换为 40-bit 哈希，在 flash 中二分查找；命中返回 sinkhole 地址，未命中转发上游 DNS。
- 以 ESP32-C3 4MB flash、无 PSRAM 板为测试目标，支持 Web 配置与后续 Wi-Fi 更新。
- 固件、黑名单以及网络 OTA 使用对应配置和认证。

**怎么利用**：用当前 PlatformIO 构建；复制 `src/secrets.example.h` 并配置 Web/OTA 凭据，按 README 烧录固件、连接 Wi-Fi，将设备 IP 配为客户端或路由器 DNS，测试拦截及未拦截查询。

**实际例子**：**可推导用法 → 场景：** 给家中网络增加轻量 DNS 黑名单。**输入：** ESP32-C3、稳定 USB 供电、Wi-Fi 与黑名单。**操作：** 烧录并设置 DNS，在客户端查询黑名单域名和正常域名。**输出：** 命中域名被 sinkhole，其他请求转发至上游，需确认正常网站仍可访问。

**局限 / 注意点**：只能按 DNS 域名拦截，不能阻止所有同域广告或绕过本地 DNS 的流量；40-bit 哈希存在碰撞概率，供电与 Wi-Fi 质量会影响稳定性。Web/OTA 密码不可留空。
