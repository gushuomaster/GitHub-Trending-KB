# AI

AI 相关 GitHub 项目的主题入口。

## 项目

- [[heygen-com-hyperframes]] — Agent 驱动的程序化视频生成框架，使用 HTML/CSS/动画并渲染 MP4
- [[affaan-m-ECC]] — 跨 Coding Agent 的 Skills、Rules、Memory、Hooks、Security、Orchestration、Testing 工程化框架
- [[mksglu/context-mode]] — 通过 Hooks/MCP/沙箱减少 Agent 工具输出占用的上下文与 Token
- [[cathrynlavery-diagram-design]] — 让 Coding Agent 生成专业 HTML+SVG 架构图、流程图、时序图等
- [[microsoft-markitdown]] — 将 PDF/Word/Excel/PPT/HTML 等转换为更适合 LLM/RAG 的 Markdown
- [[browser-use-browser-use]] — 让 LLM/Agent 操作浏览器进行点击、输入、滚动、提取、上传和表单任务
- [[The-Swarm-Corporation-AutoHedge]] — 多 Agent 交易框架，将研究、量化、风险与执行职责分离
- [[ayghri-i-have-adhd]] — 约束 Coding Agent 输出行为，减少冗余并突出下一步动作
